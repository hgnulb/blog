    题目描述

    ✅ 861. 翻转矩阵后的得分

    题意分析

    可以翻转整个二值矩阵的任意行或列，将每行看作二进制数，求所有行数值之和的最大值。

    解法：位权贪心 + 逻辑翻转

    核心思路

    [!blue]
    先保证每行最高位为一，再独立优化其余列。 最高位的权重超过同一行其余位权之和，因此最优结果中每行首位都应为一。任意方案同时额外翻转全部行和全部列，每格被翻两次，最终结果不变，所以可以约定首列不作列翻转，再由原首位确定每行是否翻转。

    行状态确定后，各列贡献相互独立。某列有 ones 个一，翻转后就有 m-ones 个一，取两者较大值乘对应位权。实现无需真的修改矩阵，用原格值异或该行的翻转标记即可统计。

    解题步骤

    1. 将首列全一的贡献计入初始答案。
    2. 逐个处理剩余列，按原首位推算行翻转后的格值。
    3. 比较翻列前后的一个数，取较多者。
    4. 乘当前列位权并累加。

    示例：[[0,0,1,1],[1,0,1,0],[1,1,0,0]] 先逻辑翻转第一行，再翻转后两列，三行数值为 15、9、15，最高总分为 39。 [[1,1],[1,0]] 的最优得分是五；[[0,1],[1,0]] 则可以达到六，不能把两者混为同一例。

    代码实现

    class Solution {
    public int matrixScore(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;

        int answer = m * (1 << (n - 1));

        for (int j = 1; j < n; j++) {
            int ones = 0;

            for (int i = 0; i < m; i++) {
                // 行翻转由首位决定，同一行所有格子使用相同翻转标记。
                int rowFlip = grid[i][0] == 0 ? 1 : 0;

                ones += grid[i][j] ^ rowFlip;
            }

            // 当前列可翻或不翻，选择一的数量更多的一种。
            int best = Math.max(ones, m - ones);

            answer += best * (1 << (n - 1 - j));
        }

        return answer;
    }
}

    func matrixScore(grid [][]int) int {
    m := len(grid)
    n := len(grid[0])

    answer := m * (1 << (n - 1))
    for j := 1; j < n; j++ {
        ones := 0
        for i := 0; i < m; i++ {
            // 行翻转由首位决定，同一行所有格子使用相同翻转标记。
            rowFlip := 0
            if grid[i][0] == 0 {
                rowFlip = 1
            }
            ones += grid[i][j] ^ rowFlip
        }
        // 当前列可翻或不翻，选择一的数量更多的一种。
        best := ones
        if m-ones > best {
            best = m - ones
        }
        answer += best * (1 << (n - 1 - j))
    }
    return answer
}

    复杂度分析

    • 时间复杂度：$O(mn)$。
    • 空间复杂度：$O(1)$，只计算逻辑翻转，不修改输入矩阵。

    关键点总结

    [!green]

    • 最高位优先由位权大小严格保证。
    • 列翻转只改变本列贡献，可以独立选多数。
    • 行翻转标记由首位决定，在同一行内保持一致。

    易错点总结

    [!yellow]

    • 忽略行翻转，直接统计原列中一的个数：后续列的有效格值不正确。
    • 把位权写成从左到右递增：高低位含义反了。
    • 已经计入首列，又在循环里重复累计：最高位被算两次。
    • 只取 ones，不考虑 m-ones：漏掉翻列可以增加得分的情况。
