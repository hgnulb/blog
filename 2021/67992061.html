    题目描述

    ✅ 637. 二叉树的层平均值

    题意分析

    按层返回二叉树节点值的平均数。每层需要独立的节点和与节点数量，除法必须保留小数。

    解法：层序遍历

    核心思路

    [!blue]

    层序遍历在每层开始时固定队列中的本层数量，再恰好处理这些节点。新入队孩子留给下一层，本层数量同时就是平均数的分母。

    每层重新清零总和，使用足够宽的求和类型，并在除法之前转为浮点，避免整数截断。

    解题步骤

    • 根入队，空树返回空结果。
    • 冻结本层数量，累加本层节点值。
    • 将非空孩子加入队列。
    • 整层结束后用浮点除法计算平均值。

    各层为 [3]、[9,20]、[15,7]，平均值是 [3.0,14.5,11.0]。 一层为 [-5,-9] 时平均负七；两节点均为32位最大整数时，总和需宽整数，平均仍等于该最大值。

    代码实现

    class Solution {
    // 每层结束后计算平均值并加入结果。
    public List<Double> averageOfLevels(TreeNode root) {
        List<Double> res = new ArrayList<>();

        if (root == null) {
            return res;
        }

        Deque<TreeNode> queue = new ArrayDeque<>();

        queue.offer(root);

        while (!queue.isEmpty()) {
            // 固定本层节点数量，孩子留给下一层
            int size = queue.size();
            long sum = 0;

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();

                sum += node.val;

                if (node.left != null) {
                    queue.offer(node.left);
                }

                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            // 先转浮点再除，避免整数除法截断
            res.add(sum * 1.0 / size);
        }

        return res;
    }
}

    func averageOfLevels(root *TreeNode) []float64 {
    // 每层结束后计算平均值并加入结果。
    res := make([]float64, 0)
    if root == nil {
        return res
    }

    queue := make([]*TreeNode, 0)
    queue = append(queue, root)

    for len(queue) > 0 {
        // 固定本层节点数量，孩子留给下一层
        size := len(queue)
        var sum int64

        for i := 0; i < size; i++ {
            node := queue[i]
            sum += int64(node.Val)

            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        // 先转浮点再除，避免整数除法截断
        res = append(res, float64(sum)/float64(size))
        queue = queue[size:]
    }

    return res
}

    复杂度分析

    • 时间复杂度：$O(n)$，每个节点处理一次。
    • 空间复杂度：$O(w)$ 的队列规模，w 为最大层宽，不计输出。

    关键点总结

    [!green]

    • 分母是开始时固定的本层数量，不是处理途中变化的队列长度。
    • 先做整数除法再转浮点，已经丢失的小数无法恢复。
    • Go 按层截掉已处理前缀，与保留全部历史的追加队列不同。

    易错点总结

    [!yellow]

    • 总和不逐层清零，会混入以前层的值。
    • 用窄整数累加大量大节点值，可能在除法前溢出。
    • 把平均值追加放进节点循环，会让一层输出多个数。
