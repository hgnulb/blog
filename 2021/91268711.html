    题目描述

    ✅ 1341. 电影评分

    题意分析

    分别找出评分电影数量最多的用户，以及指定月份平均评分最高的电影。指标并列时取名称字典序最小者，按用户、电影的顺序返回。

    解法：SQL 查询建模

    核心思路

    [!blue]
    分别按正确粒度聚合，再合并两个结果。 用户统计使用全部评分记录，按用户分组计数；电影统计先筛选 2020 年 2 月，再按电影求平均。两个范围与指标不能混用。

    每个子查询按指标降序、名称升序取第一项，再带上顺序编号 1、2，用 UNION ALL 拼接。最外层按编号排序，只输出 results 列。

    日期条件使用 created_at≥2020-02-01 且 created_at<2020-03-01，完整覆盖闰年的二月。

    解题步骤

    1. 用户子查询按评分条数降序、用户名升序，取一行。
    2. 电影子查询先过滤日期，再按平均评分降序、片名升序，取一行。
    3. 附加各自的排序号并合并。
    4. 按排序号输出，保证用户在前、电影在后。

    示例：Daniel 与 Monica 都有 3 条评分时，选择 Daniel；Frozen 2 与 Joker 的二月均分同为 3.5 时，选择 Frozen 2。名称排序用于解决指标并列。

    代码实现

    SELECT results
FROM (
    SELECT top_user.results, 1 AS sort_order
    FROM (
        SELECT u.name AS results
        FROM MovieRating AS r
        JOIN Users AS u ON u.user_id = r.user_id
        GROUP BY r.user_id, u.name
        -- 先按全部评分数量选用户，并列时按名称选最小。
        ORDER BY COUNT(*) DESC, u.name ASC
        LIMIT 1
    ) AS top_user

    UNION ALL

    SELECT top_movie.results, 2 AS sort_order
    FROM (
        SELECT m.title AS results
        FROM MovieRating AS r
        JOIN Movies AS m ON m.movie_id = r.movie_id
        -- 先限定二月记录，再参与后面的电影平均分计算。
        WHERE r.created_at >= '2020-02-01'
          AND r.created_at < '2020-03-01'
        GROUP BY r.movie_id, m.title
        -- 电影按平均分排序，不按评分总和。
        ORDER BY AVG(r.rating) DESC, m.title ASC
        LIMIT 1
    ) AS top_movie
) AS ranked
-- 显式保证用户结果在前、电影结果在后。
ORDER BY sort_order;

    复杂度分析

    • 时间复杂度：取决于连接和聚合计划。在线性连接与聚合计划下，评分记录处理为 $O(R)$，组结果排序为 $O(G\log(G+1))$。
    • 空间复杂度：聚合与组排序需要 $O(G)$ 级状态，实际还受执行器中间结果策略影响。

    关键点总结

    [!green]

    • 用户统计不限月份，电影均分需要先筛月份。
    • 每个子查询都保留完整的指标与名称双排序键。
    • 显式顺序编号决定最终两类结果的排列次序。

    易错点总结

    [!yellow]

    • 对电影使用总分而不是平均分：评分多的电影可能获得不应有的优势。
    • 先计算全年均分再筛月份：月份外的评分已混入结果。
    • 省略名称排序键：并列指标下不保证选到字典序最小者。
    • 结束日期只写到二月二十八日：会漏掉闰日。
