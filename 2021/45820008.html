    题目描述

    ✅ 1504. 统计全 1 子矩形

    题意分析

    统计矩阵中元素全部为 1 的子矩形数量，每种上下左右边界都算一个矩形。

    解法：逐行高度 + 单调栈计数

    核心思路

    [!blue]
    逐行转成柱状图，统计以当前行为底边的矩形。 height[j] 表示当前列向上连续 1 的高度，遇到 0 就清零。ending[j] 是以 j 为右端点的所有区间最小高度之和，也就是对应矩形的数量。

    维护高度严格递增的下标栈，弹出大于等于当前高度的位置。栈顶 p 是左侧最近的更矮位置：左端点在 p 右边的 j-p 个区间最小值均为 height[j]；左端点不超过 p 的区间复用 ending[p]，因此 ending[j]=ending[p]+height[j]*(j-p)。

    没有更矮位置时，j+1 个区间都以当前高度为最小值，贡献为 height[j]*(j+1)。将每个 ending[j] 加入总答案。

    解题步骤

    1. 处理一行，更新各列连续高度。
    2. 清空当前行的栈，从左向右枚举右端点。
    3. 弹出不低于当前高度的栈顶，计算 ending。
    4. 累加贡献，将当前下标入栈。

    示例：[[1,0,1],[1,1,0],[1,1,0]] 的逐行高度为 [1,0,1]、[2,1,0]、[3,2,0]。以各行为底边的矩形数为 2、4、7，总数 13。

    代码实现

    class Solution {
    public int numSubmat(int[][] mat) {
        int columns = mat[0].length;
        int[] heights = new int[columns];
        int[] ending = new int[columns];
        int[] stack = new int[columns];
        int answer = 0;

        for (int[] row : mat) {
            for (int col = 0; col < columns; col++) {
                heights[col] = row[col] == 0 ? 0 : heights[col] + 1;
            }

            // 当前行重新建立单调关系，不能复用上一行的栈。
            int top = -1;

            for (int right = 0; right < columns; right++) {
                // 弹出不更矮的位置，留下最近的严格更矮下标。
                while (top >= 0 && heights[stack[top]] >= heights[right]) {
                    top--;
                }

                int previous = top >= 0 ? stack[top] : -1;

                // 右侧新区间贡献当前高度；更左区间复用本行前驱贡献。
                ending[right] =
                        (previous >= 0 ? ending[previous] : 0)
                                + heights[right] * (right - previous);
                answer += ending[right];
                stack[++top] = right;
            }
        }

        return answer;
    }
}

    func numSubmat(mat [][]int) int {
    columns := len(mat[0])
    heights := make([]int, columns)
    ending := make([]int, columns)
    stack := make([]int, columns)
    answer := 0

    for _, row := range mat {
        for col := 0; col < columns; col++ {
            if row[col] == 0 {
                heights[col] = 0
            } else {
                heights[col]++
            }
        }

        // 当前行重新建立单调关系，不能复用上一行的栈。
        top := -1
        for right := 0; right < columns; right++ {
            // 弹出不更矮的位置，留下最近的严格更矮下标。
            for top >= 0 && heights[stack[top]] >= heights[right] {
                top--
            }
            previous := -1
            if top >= 0 {
                previous = stack[top]
            }
            // 右侧新区间贡献当前高度；更左区间复用本行前驱贡献。
            ending[right] = heights[right] * (right - previous)
            if previous >= 0 {
                ending[right] += ending[previous]
            }
            answer += ending[right]
            top++
            stack[top] = right
        }
    }
    return answer
}

    复杂度分析

    • 时间复杂度：$O(mn)$，每行的下标最多各入栈、出栈一次。
    • 空间复杂度：$O(n)$，保存高度、当前行贡献和栈。

    关键点总结

    [!green]

    • 水平区间能向上延伸多少层，取决于区间最小高度。
    • ending[p] 已在当前行算好，可以复用。
    • 每行重置栈，ending 从左向右覆盖，不依赖上一行旧值。

    易错点总结

    [!yellow]

    • 遇到 0 不清空高度：把不连续的 1 连成矩形。
    • 只累加高度：漏掉跨列矩形。
    • 复用上一行的栈：柱高变化后不再满足单调关系。
    • 宽度写成 j-p+1：p 属于复用部分，会重复计数。
