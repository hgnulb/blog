    题目描述

    ✅ 1166. 设计文件系统

    题意分析

    维护完整路径对应的值。创建路径时，路径必须尚不存在，父路径必须已存在；查询不存在的路径返回 -1。

    解法：哈希表记录路径

    核心思路

    [!blue]
    哈希表保存完整路径与值。 本题按完整路径创建和查询，不需要列目录，因此不必构造树节点。父子关系由路径字符串本身提供：最后一个斜杠之前就是父路径。

    预置根路径作为存在性哨兵。一级路径截出的父串为空，将它映射回根，再执行统一的父路径检查。所有检查通过之后才能写入新键，失败时不能改变表中内容。

    解题步骤

    1. 初始化哈希表，放入根路径哨兵。
    2. 创建时先拒绝已经存在的路径。
    3. 从最后一个斜杠截取父路径，一级路径的父映射为根。
    4. 父路径存在时写入并返回 true，否则返回 false。
    5. 查询直接按键取值，未命中返回 -1。

    示例：先创建 /leet=1，再创建 /leet/code=2，均成功。未创建 /c 时，创建 /c/d 应失败。重复创建 /leet 也应失败，原值仍为 1。

    代码实现

    class FileSystem {
    private final Map<String, Integer> values;

    public FileSystem() {
        // 根作为哨兵预置，让一级路径的父检查自然命中。
        this.values = new HashMap<>();
        values.put("/", -1);
    }

    public boolean createPath(String path, int value) {
        if (values.containsKey(path)) {
            return false;
        }

        // 父路径是最后一个 '/' 之前的部分；一级路径截出空串，映射回根。
        int idx = path.lastIndexOf('/');
        String parent = path.substring(0, idx);

        if (parent.isEmpty()) {
            parent = "/";
        }

        if (!values.containsKey(parent)) {
            return false;
        }

        // 查重和父路径验证都通过后，才真正创建路径。
        values.put(path, value);

        return true;
    }

    public int get(String path) {
        return values.getOrDefault(path, -1);
    }
}

    import "strings"

type FileSystem struct {
    values map[string]int
}

func Constructor() FileSystem {
    // 根作为哨兵预置，让一级路径的父检查自然命中。
    return FileSystem{
        values: map[string]int{"/": -1},
    }
}

func (fs *FileSystem) CreatePath(path string, value int) bool {
    if _, ok := fs.values[path]; ok {
        return false
    }

    // 父路径是最后一个 '/' 之前的部分；一级路径截出空串，映射回根。
    idx := strings.LastIndex(path, "/")
    parent := path[:idx]
    if parent == "" {
        parent = "/"
    }

    if _, ok := fs.values[parent]; !ok {
        return false
    }

    // 查重和父路径验证都通过后，才真正创建路径。
    fs.values[path] = value
    return true
}

func (fs *FileSystem) Get(path string) int {
    if v, ok := fs.values[path]; ok {
        return v
    }
    return -1
}

    复杂度分析

    • 时间复杂度：期望 $O(L)$，L 为输入路径长度，包括字符串哈希和父路径提取。
    • 空间复杂度：已保存路径总长度为 S，持久存储为 $O(S)$；创建时还可能产生长度为 $O(L)$ 的临时父路径。

    关键点总结

    [!green]

    • 完整路径查表满足现有接口，不需维护子节点列表。
    • 父路径取最后一个分隔符之前的部分。
    • 查重和父路径验证完成前，不修改哈希表。

    易错点总结

    [!yellow]

    • 一级路径的空父串没有映射到根：/a 会被错误拒绝。
    • 使用第一个斜杠截父路径：深层路径会错误地直接以根为父，绕过父路径存在性要求。
    • 先写入再验证父路径：即使返回 false，也已经留下非法路径。
    • 重复创建覆盖旧值：创建失败应保持原值不变。
