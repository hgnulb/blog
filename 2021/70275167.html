    题目描述

    ✅ 218. 天际线问题

    题意分析

    求所有矩形建筑叠加后的最高轮廓，用高度变化处的关键点表示，相邻输出点不能保持相同高度。

    解法：扫描线 + 高度多重集合

    核心思路

    [!blue]
    只在建筑左右端点更新活跃高度。 左端点加入高度，右端点移除高度，同一横坐标的全部事件处理完后再读取最大值，避免把中间状态当作真实轮廓。

    相同高度可能属于多栋建筑，需要记录次数。Java 用有序映射维护高度与计数；Go 用计数表记录当前有效数量，最大堆保留候选高度，在读取前清理计数为零的堆顶。Go 堆中可能仍有尚未浮到顶部的失效项。

    最高值与上次输出高度不同才记录关键点。预置高度零表示地面，所有建筑结束后自然输出落地位置。

    解题步骤

    1. 每栋建筑拆成加入、移除两个事件，按横坐标排序。
    2. 初始化地面高度与上次轮廓。
    3. 批量处理同一横坐标事件，更新高度次数。
    4. 取得有效最高高度，变化时输出关键点。

    示例：[[1,3,4],[3,5,4]] 在 x=3 一栋结束、一栋开始，整批处理后高度仍为 4，只输出 [[1,4],[5,0]]。等高建筑重叠时，一栋结束只能减少一份计数。

    代码实现

    class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        int[][] events = new int[buildings.length * 2][2];
        int index = 0;

        for (int[] building : buildings) {
            events[index++] = new int[] {building[0], -building[2]};
            events[index++] = new int[] {building[1], building[2]};
        }

        Arrays.sort(events, (a, b) -> Integer.compare(a[0], b[0]));

        TreeMap<Integer, Integer> heightCount = new TreeMap<>();

        // 地面始终有效，建筑全部结束后最高值自然回到零。
        heightCount.put(0, 1);
        List<List<Integer>> res = new ArrayList<>();
        int i = 0;
        int prevHeight = 0;

        while (i < events.length) {
            int x = events[i][0];

            // 同一坐标的事件全部更新后，才能读取最终轮廓。
            while (i < events.length && events[i][0] == x) {
                int height = events[i][1];

                if (height < 0) {
                    int actualHeight = -height;

                    heightCount.put(actualHeight, heightCount.getOrDefault(actualHeight, 0) + 1);
                } else {
                    int count = heightCount.get(height);

                    if (count == 1) {
                        heightCount.remove(height);
                    } else {
                        heightCount.put(height, count - 1);
                    }
                }

                i++;
            }

            int curHeight = heightCount.lastKey();

            if (curHeight != prevHeight) {
                res.add(Arrays.asList(x, curHeight));
                prevHeight = curHeight;
            }
        }

        return res;
    }
}

    import (
    "container/heap"
    "sort"
)

type maxHeap []int

func (h maxHeap) Len() int { return len(h) }

func (h maxHeap) Less(i, j int) bool { return h[i] > h[j] }

func (h maxHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }

func (h *maxHeap) Push(value any) {
    *h = append(*h, value.(int))
}

func (h *maxHeap) Pop() any {
    old := *h
    value := old[len(old)-1]
    *h = old[:len(old)-1]
    return value
}

func getSkyline(buildings [][]int) [][]int {
    events := make([][2]int, 0, len(buildings)*2)
    for _, building := range buildings {
        events = append(events, [2]int{building[0], -building[2]})
        events = append(events, [2]int{building[1], building[2]})
    }
    sort.Slice(events, func(i, j int) bool {
        return events[i][0] < events[j][0]
    })

    // 地面始终有效，建筑全部结束后最高值自然回到零。
    heightCount := map[int]int{0: 1}
    heights := &maxHeap{0}
    heap.Init(heights)
    result := make([][]int, 0)
    previousHeight := 0

    for i := 0; i < len(events); {
        x := events[i][0]
        // 同一坐标的事件全部更新后，才能读取最终轮廓。
        for i < len(events) && events[i][0] == x {
            height := events[i][1]
            if height < 0 {
                height = -height
                heightCount[height]++
                heap.Push(heights, height)
            } else {
                heightCount[height]--
            }
            i++
        }

        // 堆中可能残留失效高度，读最大值前清理零计数堆顶。
        for heightCount[(*heights)[0]] == 0 {
            heap.Pop(heights)
        }
        currentHeight := (*heights)[0]
        if currentHeight != previousHeight {
            result = append(result, []int{x, currentHeight})
            previousHeight = currentHeight
        }
    }

    return result
}

    复杂度分析

    • 时间复杂度：$O(n\log(n+1))$，排序与高度维护占主导；Go 每份入堆记录最多清理一次。
    • 空间复杂度：$O(n)$，保存事件、高度结构与结果。

    关键点总结

    [!green]

    • 同坐标先完成全部更新，再判断轮廓变化。
    • 计数表维护真实有效数量，惰性堆只需保证读出的最大值有效。
    • 建筑在右端点结束，不推迟到下一整数坐标。

    易错点总结

    [!yellow]

    • 每处理一条事件就输出：同一横坐标可能出现相互抵消的假变化。
    • 结束时直接删除整个高度键：可能同时删掉其他等高建筑的贡献。
    • 结束事件直接弹最大堆顶：结束的建筑未必是最高者。
    • Go 不清理失效堆顶：已经结束的高楼继续遮挡真实轮廓。
