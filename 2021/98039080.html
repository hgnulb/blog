    题目描述

    ✅ 1420. 生成数组

    题意分析

    统计长度为 n、取值在 1 到 m 的数组中，扫描时当前最大值恰好刷新 k 次的方案数。首个元素一定刷新一次。

    解法：DP + 前缀和优化

    核心思路

    [!blue]
    按当前最大值和刷新次数计数。 dp[maximum][cost] 表示已处理长度下，最大值恰为 maximum、刷新次数恰为 cost 的数组数量。单元素数组对应 dp[maximum][1]=1。

    追加元素得到新最大值 maximum 有两类来源：不刷新时，新元素可取 1 到 maximum，共 maximum 种；刷新时，新元素固定为 maximum，旧最大值必须严格更小，旧 cost 少一次。

    固定 cost 后递增枚举 maximum，用 smaller 保存严格更小旧最大值的状态和。先计算当前结果，再把当前旧状态加入 smaller，避免将相等最大值误算成刷新。

    解题步骤

    1. k 为 0 或超过 n、m 时返回 0。
    2. 初始化长度为 1 的状态。
    3. 逐步增加长度，新建 next 保存下一层。
    4. 对每个 cost 重置 smaller，按 maximum 递增完成两类转移并取模。
    5. 最后汇总所有最大值对应的 cost=k 状态。

    示例：n=3、m=2、k=2 时，合法数组为 [1,1,2]、[1,2,1]、[1,2,2]，答案为 3。最后一种说明追加值等于当前最大值时不会刷新。

    代码实现

    class Solution {
    private static final int MOD = 1_000_000_007;

    public int numOfArrays(int n, int m, int k) {
        if (k == 0 || k > n || k > m) {
            return 0;
        }

        int[][] dp = new int[m + 1][k + 1];

        for (int maximum = 1; maximum <= m; maximum++) {
            // 单元素数组首次刷新最大值，搜索代价恰为一。
            dp[maximum][1] = 1;
        }

        for (int length = 2; length <= n; length++) {
            int[][] next = new int[m + 1][k + 1];

            for (int cost = 1; cost <= Math.min(k, length); cost++) {
                // 每个 cost 单独累积严格更小的旧最大值。
                int smaller = 0;

                for (int maximum = 1; maximum <= m; maximum++) {
                    // 不刷新时末项有 maximum 种选择，乘法先使用 64 位。
                    long keepMaximum = (long) dp[maximum][cost] * maximum;

                    next[maximum][cost] = (int) ((keepMaximum + smaller) % MOD);

                    // 当前转移完成后再加入，下一轮前缀才包含这个旧最大值。
                    smaller += dp[maximum][cost - 1];

                    if (smaller >= MOD) {
                        smaller -= MOD;
                    }
                }
            }

            dp = next;
        }

        int answer = 0;

        for (int maximum = 1; maximum <= m; maximum++) {
            answer += dp[maximum][k];

            if (answer >= MOD) {
                answer -= MOD;
            }
        }

        return answer;
    }
}

    func numOfArrays(n int, m int, k int) int {
    const mod = 1_000_000_007
    if k == 0 || k > n || k > m {
        return 0
    }

    dp := make([][]int, m+1)
    for maximum := 0; maximum <= m; maximum++ {
        dp[maximum] = make([]int, k+1)
    }
    for maximum := 1; maximum <= m; maximum++ {
        // 单元素数组首次刷新最大值，搜索代价恰为一。
        dp[maximum][1] = 1
    }

    for length := 2; length <= n; length++ {
        next := make([][]int, m+1)
        for maximum := 0; maximum <= m; maximum++ {
            next[maximum] = make([]int, k+1)
        }

        for cost := 1; cost <= k && cost <= length; cost++ {
            // 每个 cost 单独累积严格更小的旧最大值。
            smaller := 0
            for maximum := 1; maximum <= m; maximum++ {
                // 不刷新时末项有 maximum 种选择，乘法先使用 64 位。
                keepMaximum := int64(dp[maximum][cost]) * int64(maximum)
                next[maximum][cost] = int((keepMaximum + int64(smaller)) % int64(mod))

                // 当前转移完成后再加入，下一轮前缀才包含这个旧最大值。
                smaller += dp[maximum][cost-1]
                if smaller >= mod {
                    smaller -= mod
                }
            }
        }
        dp = next
    }

    answer := 0
    for maximum := 1; maximum <= m; maximum++ {
        answer += dp[maximum][k]
        if answer >= mod {
            answer -= mod
        }
    }
    return answer
}

    复杂度分析

    • 时间复杂度：通过非法 k 的前置检查后为 $O(nmk)$，前缀和消除了对旧最大值的额外枚举；前置判定无解时直接返回。
    • 空间复杂度：$O(mk)$，只保存相邻两层长度状态。

    关键点总结

    [!green]

    • 两个维度都表示恰好，不能混成不超过。
    • 不刷新分支的选择数是 maximum，包含相等值。
    • smaller 先用于转移，再加入当前旧状态。
    • 乘法使用 64 位中间量，计数及时取模。

    易错点总结

    [!yellow]

    • 不刷新乘 maximum-1：会漏掉追加相等值的方案。
    • 先增加 smaller 再计算当前状态：会把不刷新的相等值算成刷新。
    • 混用当前长度与旧长度状态：一轮转移必须读取完整上一层。
    • 首元素代价初始化为 0：非空数组第一次元素必定刷新。
