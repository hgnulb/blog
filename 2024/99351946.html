    题目描述

    ✅ 901. 股票价格跨度

    题意分析

    每天输入一个价格，返回截至今天连续多少天的价格不高于今天。维护可持续调用的数据结构，不重新扫描历史。

    解法：单调栈维护候选

    核心思路

    [!blue]

    栈中记录价格与它已包含的连续跨度，价格从底到顶严格递减。新价格从跨度一开始，将不高于自己的栈顶块逐一弹出并累加其跨度。

    这些块互不重叠且紧邻今天，合并后仍是连续区间；遇到更高价格时，它就是不能越过的边界。 若未来价格比这个新块的价格低，会先被新块挡住，无法越过它到旧块；若足够高，则能直接吸收新块连同其已包含的整段历史。

    解题步骤

    • 当天跨度初始化一。
    • 栈顶价格小于等于当天时，弹出并合并整块跨度。
    • 压入当天价格和合并后的跨度，返回跨度。

    价格 [100,80,60,70,60,75,85] 的跨度为 [1,1,1,2,1,4,6]，连续相同价格也应不断合并之前的跨度。

    代码实现

    class StockSpanner {
    private final Deque<int[]> stack = new ArrayDeque<>();

    public int next(int price) {
        int span = 1;

        while (!stack.isEmpty() && stack.peek()[0] <= price) {
            // 栈顶已经代表连续多天，合并整块跨度。
            span += stack.pop()[1];
        }

        // 将当天与被合并的历史压缩成一个新块。
        stack.push(new int[] {price, span});

        return span;
    }
}

    type StockSpanner struct {
    stack [][2]int
}

func Constructor() StockSpanner {
    return StockSpanner{stack: make([][2]int, 0)}
}

func (s *StockSpanner) Next(price int) int {
    span := 1
    for len(s.stack) > 0 && s.stack[len(s.stack)-1][0] <= price {
        // 栈顶已经代表连续多天，合并整块跨度。
        span += s.stack[len(s.stack)-1][1]
        s.stack = s.stack[:len(s.stack)-1]
    }
    // 将当天与被合并的历史压缩成一个新块。
    s.stack = append(s.stack, [2]int{price, span})
    return span
}

    复杂度分析

    • 时间复杂度：每次均摊 $O(1)$，单次最坏 $O(n)$；n 次调用总计 $O(n)$。
    • 空间复杂度：$O(n)$，价格持续下降时历史块全部保留。

    关键点总结

    [!green]

    • 栈中跨度已经压缩了被当前块覆盖的历史天数。
    • 价格相等也属于不高于，要一起合并。

    易错点总结

    [!yellow]

    • 每弹出一项只加一，会丢掉该项压缩的多天跨度。
    • 每次调用重新建栈，会失去历史信息。
    • Go 使用值接收者修改栈切片长度，更新可能无法保存在对象中。
