    题目描述

    ✅ 388. 文件的最长绝对路径

    题意分析

    按换行和行首制表符表示的目录层级，求最长文件绝对路径长度，不需要构建树或返回路径文本。

    解法：栈记录各层路径长度

    核心思路

    [!blue]

    按深度保存当前父路径前缀长度，前缀包含父目录后的斜杠。目录把自身名称长度与一条斜杠写入下一层槽，文件只加名称长度参与最大值比较。

    回到浅层时不必清空全部深层槽。有效输入的后续子条目出现前，它的父目录会重新写入对应前缀，旧分支信息不会被误读。

    解题步骤

    • 按换行拆成条目。
    • 只数行首制表符，剩余是名称。
    • 目录更新下一层前缀，文件更新最长值。

    路径 dir/subdir2/subsubdir2/file2.ext 的长度为 3+1+7+1+10+1+9=32；父路径前缀二十三加文件名九，文件末尾不补斜杠。没有文件时返回零。

    代码实现

    // 数组 stack[depth] 保存当前条目之前的父路径长度，含父目录末尾斜杠。
class Solution {
    public int lengthLongestPath(String input) {
        String[] lines = input.split("\n");
        int[] stack = new int[lines.length + 1];
        int best = 0;

        for (String line : lines) {
            int depth = 0;
            while (depth < line.length() && line.charAt(depth) == '\t') {
                depth++;
            }

            String name = line.substring(depth);

            if (name.indexOf('.') >= 0) {
                int length = stack[depth] + name.length();
                if (length > best) {
                    best = length;
                }
            } else {
                // 当前目录成为下一层的父前缀，末尾补一条斜杠
                stack[depth + 1] = stack[depth] + name.length() + 1;
            }
        }

        return best;
    }
}

    import "strings"

// 数组 stack[depth] 保存当前条目之前的父路径长度，含父目录末尾斜杠。
func lengthLongestPath(input string) int {
    lines := strings.Split(input, "\n")
    stack := make([]int, len(lines)+1)
    best := 0

    for _, line := range lines {
        depth := 0
        for depth < len(line) && line[depth] == '\t' {
            depth++
        }

        name := line[depth:]
        if strings.ContainsRune(name, '.') {
            length := stack[depth] + len(name)
            if length > best {
                best = length
            }
        } else {
            // 当前目录成为下一层的父前缀，末尾补一条斜杠
            stack[depth+1] = stack[depth] + len(name) + 1
        }
    }

    return best
}

    复杂度分析

    • 时间复杂度：$O(n)$，扫描缩进、名称与文件标记的总字符量线性。
    • 空间复杂度：$O(n)$，分行结果与按深度索引的前缀数组。

    关键点总结

    [!green]

    • 槽位保存的是当前条目之前的父路径，不含当前名称。
    • 目录追加斜杠，文件末尾不再加斜杠。

    易错点总结

    [!yellow]

    • 目录写当前层而非下一层，会污染兄弟前缀。
    • 文件也加一，会多算尾部斜杠。
    • 以第一行长度初始化答案，会在没有文件时返回非零。
