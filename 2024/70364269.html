    题目描述

    ✅ 面试题 02.02. 返回倒数第 k 个节点

    题意分析

    返回单链表倒数第 k 个节点的值，题目保证 k 合法。倒数第一是尾节点。

    解法：快慢指针固定间距

    核心思路

    [!blue]

    让快指针先走 k 步，再与慢指针同步。同步期间从慢指针走 k 次后继正好到快指针，间距不变。

    快指针到空时，慢指针到空还有 k 步，也就是其后还有 k-1 个节点，恰好为目标。

    解题步骤

    • 两指针从头开始。
    • 快指针先走恰好 k 步。
    • 快指针未空时，两者各前进一步。
    • 返回慢指针节点值。

    一到五的链表、k=2，快指针先到三，最后越过五时慢指针在四；k 等于长度时慢指针保持在头。

    代码实现

    class Solution {
    public int kthToLast(ListNode head, int k) {
        ListNode fast = head;
        ListNode slow = head;

        // 快指针先走 k 步，以空节点作为最终参照
        for (int i = 0; i < k; i++) {
            fast = fast.next;
        }

        // 同步推进保持间距，快指针到空时慢指针即为目标
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }

        return slow.val;
    }
}

    func kthToLast(head *ListNode, k int) int {
    fast, slow := head, head

    // 快指针先走 k 步，以空节点作为最终参照
    for i := 0; i < k; i++ {
        fast = fast.Next
    }
    // 同步推进保持间距，快指针到空时慢指针即为目标
    for fast != nil {
        fast = fast.Next
        slow = slow.Next
    }
    return slow.Val
}

    复杂度分析

    • 时间复杂度：$O(n)$，快指针总共走过链表。
    • 空间复杂度：$O(1)$，两个指针。

    关键点总结

    [!green]

    • 预走 k 步与以空节点为终点配套。
    • 返回的是值，不是节点对象。

    易错点总结

    [!yellow]

    • 只预走 k-1 步会偏后一个节点。
    • 同步阶段检查快指针后继非空，会提前一轮结束。
    • 同步时只移动快指针，慢指针始终停在头。
