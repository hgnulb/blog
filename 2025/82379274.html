    题目描述

    ✅ 面试题 16.22. 兰顿蚂蚁

    题意分析

    模拟兰顿蚂蚁：初始全白、朝右，白格右转并翻黑，黑格左转并翻白，之后前进一步，输出覆盖全部足迹的最小矩形。

    解法：黑格集合 + 足迹边界

    核心思路

    [!blue]
    用集合保存黑格，白色作为默认状态。 每步根据当前位置是否在集合中决定转向与颜色翻转，再按新方向移动。这样不必为无限网格预先开二维数组，负坐标也能直接记录。

    方向按上、右、下、左的顺时针顺序编码，右转加一、左转加三并对四取模。每次移动更新足迹的行列极值，结束后才按包围矩形创建输出网格。

    先写黑格，最后用朝向字符覆盖蚂蚁当前位置；所有坐标减去最小行列值，映射到输出数组的非负下标。

    解题步骤

    1. 初始化朝右、原点位置、空黑格集合和原点边界。
    2. 按当前颜色转向并翻转集合成员状态。
    3. 向新方向移动，更新全部足迹边界。
    4. 创建结果矩形，先填颜色再填蚂蚁朝向。

    示例：两步后，原点与它下方的格子为黑，蚂蚁位于左下方并朝左，输出 [_X,LX]。零步时只输出 [R]。

    代码实现

    class Solution {
    public List<String> printKMoves(int K) {
        int[] dr = {-1, 0, 1, 0};
        int[] dc = {0, 1, 0, -1};
        char[] dirChar = {'U', 'R', 'D', 'L'};

        Set<Long> black = new HashSet<>();
        int r = 0;
        int c = 0;
        // 方向按上右下左排列，下标一表示初始朝右。
        int dir = 1;
        int minR = 0;
        int maxR = 0;
        int minC = 0;
        int maxC = 0;

        for (int step = 0; step < K; step++) {
            long key = (((long) r) << 32) ^ (c & 0xffffffffL);

            if (black.contains(key)) {
                dir = (dir + 3) % 4;
                black.remove(key);
            } else {
                dir = (dir + 1) % 4;
                black.add(key);
            }

            // 按刚完成的转向移动，再将新位置纳入全部足迹边界。
            r += dr[dir];
            c += dc[dir];
            minR = Math.min(minR, r);
            maxR = Math.max(maxR, r);
            minC = Math.min(minC, c);
            maxC = Math.max(maxC, c);
        }

        int rows = maxR - minR + 1;
        int cols = maxC - minC + 1;
        char[][] grid = new char[rows][cols];

        for (int i = 0; i < rows; i++) {
            Arrays.fill(grid[i], '_');
        }

        for (long key : black) {
            int br = (int) (key >> 32);
            int bc = (int) key;

            grid[br - minR][bc - minC] = 'X';
        }

        // 最后写蚂蚁朝向，覆盖当前格原本的颜色。
        grid[r - minR][c - minC] = dirChar[dir];

        List<String> answer = new ArrayList<>();

        for (int i = 0; i < rows; i++) {
            answer.add(new String(grid[i]));
        }

        return answer;
    }
}

    func printKMoves(K int) []string {
    dr := []int{-1, 0, 1, 0}
    dc := []int{0, 1, 0, -1}
    dirChar := []byte{'U', 'R', 'D', 'L'}

    type Point struct{ r, c int }
    black := make(map[Point]bool)

    // 方向按上右下左排列，下标一表示初始朝右。
    r, c, dir := 0, 0, 1
    minR, maxR, minC, maxC := 0, 0, 0, 0

    for step := 0; step < K; step++ {
        p := Point{r: r, c: c}
        if black[p] {
            dir = (dir + 3) % 4
            delete(black, p)
        } else {
            dir = (dir + 1) % 4
            black[p] = true
        }

        // 按刚完成的转向移动，再将新位置纳入全部足迹边界。
        r += dr[dir]
        c += dc[dir]

        if r < minR {
            minR = r
        }
        if r > maxR {
            maxR = r
        }
        if c < minC {
            minC = c
        }
        if c > maxC {
            maxC = c
        }
    }

    rows := maxR - minR + 1
    cols := maxC - minC + 1
    grid := make([][]byte, rows)
    for i := 0; i < rows; i++ {
        grid[i] = make([]byte, cols)
        for j := 0; j < cols; j++ {
            grid[i][j] = '_'
        }
    }

    for p := range black {
        grid[p.r-minR][p.c-minC] = 'X'
    }
    // 最后写蚂蚁朝向，覆盖当前格原本的颜色。
    grid[r-minR][c-minC] = dirChar[dir]

    answer := make([]string, rows)
    for i := 0; i < rows; i++ {
        answer[i] = string(grid[i])
    }
    return answer
}

    复杂度分析

    • 时间复杂度：期望 $O(K+A)$，K 为模拟步数，A 为最终矩形面积，包含输出构造。
    • 空间复杂度：$O(K+A)$，黑格集合和输出矩阵。

    关键点总结

    [!green]

    • 颜色判断在移动前，移动使用转向后的方向。
    • 边界覆盖全部足迹，包括起点和终点。
    • 蚂蚁朝向字符最后写入，覆盖所在格颜色。

    易错点总结

    [!yellow]

    • 黑格翻白时不从集合删除：后续访问和最终输出仍把它当黑格。
    • 先移动再转向：第一步方向就与规则不同。
    • 只按黑格确定边框：可能遗漏最终蚂蚁位置或已有足迹。
    • 负坐标直接作数组下标：输出时必须减去最小坐标平移。
