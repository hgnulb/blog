    ✅ 738. 单调递增的数字

    题意分析

    求不超过 n、各位从左到右不下降的最大整数。相等位允许出现，单调递增在本题中不是严格递增。

    解法：从右向左修正

    核心思路

    [!blue]

    相邻左位大于右位时，需要让左位减一，才能为右侧腾出取最大值九的空间。减一可能让它又小于更左一位，因此从右向左检查，将连锁修正向左传播。

    mark 只表示最终要填九的后缀起点，不保证扫描时原始后缀已经有序。先完成全部减一，再统一填九，既保留连锁判断，也使结果在不超过原数的前提下尽量大。

    解题步骤

    • 转为可修改的十进制位数组，mark 初始为长度。
    • 从右向左检查下降，左位减一并将 mark 移到右位。
    • 扫描后把 mark 起的后缀全部置九。
    • 转回整数，自动去除前导零。

    332→322→222，最终从下标一填九得 299；十变为 09 后返回九；1234 不发生修正。

    代码实现

    class Solution {
    public int monotoneIncreasingDigits(int n) {
        char[] digits = String.valueOf(n).toCharArray();
        // 记录待填九的后缀起点，初始表示空后缀
        int mark = digits.length;

        for (int i = digits.length - 1; i > 0; i--) {
            if (digits[i - 1] > digits[i]) {
                // 减少左位后可能继续向左产生下降，交给下一轮检查
                digits[i - 1]--;
                mark = i;
            }
        }

        // 所有连锁修正完成后，再将后缀最大化
        for (int i = mark; i < digits.length; i++) {
            digits[i] = '9';
        }

        return Integer.parseInt(new String(digits));
    }
}

    import "strconv"

func monotoneIncreasingDigits(n int) int {
    digits := []byte(strconv.Itoa(n))
    // 记录待填九的后缀起点，初始表示空后缀
    mark := len(digits)
    for i := len(digits) - 1; i > 0; i-- {
        if digits[i-1] > digits[i] {
            // 减少左位后可能继续向左产生下降，交给下一轮检查
            digits[i-1]--
            mark = i
        }
    }
    // 所有连锁修正完成后，再将后缀最大化
    for i := mark; i < len(digits); i++ {
        digits[i] = '9'
    }
    ans, _ := strconv.Atoi(string(digits))
    return ans
}

    复杂度分析

    • 时间复杂度：$O(d)$，d 为十进制位数。
    • 空间复杂度：$O(d)$，保存可修改位数组。

    关键点总结

    [!green]

    • 修正向左传播，填九延迟到扫描完成。
    • mark=长度 表示没有待填后缀。

    易错点总结

    [!yellow]

    • 只改最先发现的下降就结束，会将三三二变成仍非法的三二九。
    • 不填九虽可能合法，却不是最大答案。
    • 把相等位也当成下降，会排除合法的重复数字。
