    题目描述

    ✅ 841. 钥匙和房间

    题意分析

    从零号房间出发收集钥匙，判断是否能访问所有房间。钥匙关系是有向图，只需一次可达性遍历。

    解法：BFS 扩展可达房间

    核心思路

    [!blue]

    房间第一次发现时即标记并计数，再进入队列展开钥匙。同一房间无需因不同访问路径重复处理，因为能取得的钥匙集合相同。

    起点零本来可进入，先计入一次；最终比较访问数量与房间总数。

    解题步骤

    • 起点入队、标记，计数一。
    • 逐个读取房间钥匙，只将新房间标记并入队。
    • 队列耗尽后比较数量。

    零无钥匙，而一、二互有钥匙，仍无法从零进入它们，结果假。 两条路径汇合到同一房间时只计一次；不可达连通块内部互有钥匙，也不能凭空进入。

    代码实现

    class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        boolean[] visited = new boolean[rooms.size()];
        Queue<Integer> queue = new ArrayDeque<>();

        queue.offer(0);
        // 起点先标记，指回起点的钥匙不会重复计数
        visited[0] = true;
        int count = 1;

        while (!queue.isEmpty()) {
            int room = queue.poll();

            for (int next : rooms.get(room)) {
                if (!visited[next]) {
                    // 第一次发现即标记，计数与入队同步
                    visited[next] = true;
                    count++;
                    queue.offer(next);
                }
            }
        }

        return count == rooms.size();
    }
}

    func canVisitAllRooms(rooms [][]int) bool {
    visited := make([]bool, len(rooms))
    queue := make([]int, 0)

    queue = append(queue, 0)
    // 起点先标记，指回起点的钥匙不会重复计数
    visited[0] = true
    count := 1

    head := 0
    for head < len(queue) {
        room := queue[head]
        head++
        for _, next := range rooms[room] {
            if !visited[next] {
                // 第一次发现即标记，计数与入队同步
                visited[next] = true
                count++
                queue = append(queue, next)
            }
        }
    }

    return count == len(rooms)
}

    复杂度分析

    • 时间复杂度：$O(n+m)$，n 为房间数、m 为钥匙数。
    • 空间复杂度：$O(n)$，访问表与队列。

    关键点总结

    [!green]

    • 存在钥匙指向房间，不代表钥匙可以从零拿到。
    • 计数对应首次标记，不是出队或钥匙数量。

    易错点总结

    [!yellow]

    • 起点未标记，会被指回零的钥匙重复计数。
    • 只检查入度，会接受与起点隔离的环。
    • 发现时不标记却增加计数，会重复统计同一房间。
