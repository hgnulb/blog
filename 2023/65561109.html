    LeetCode 1239. 串联字符串的最大长度

    2023-06-10 HGNULB 约 5 分钟
    文章信息 6 个分类 · 4 个标签

    LeetCode CodeTop 中等 未解决 1-2 华为

    题目描述

    ✅ 1239. 串联字符串的最大长度

    题意分析

    从字符串数组中选取若干项按原顺序拼接，要求结果字符不重复，求最大长度。最多 16 个字符串，可以枚举选或不选。

    解法：位掩码 + 回溯

    核心思路

    [!blue]
    预处理字符掩码，再回溯选择。 字符串自身若含重复字符，任何方案都不能选择它；其他字符串用 26 位掩码表示字符集合，并保存长度。

    dfs(idx,mask) 表示当前已经使用 mask 中字符，从 idx 及之后还能新增多少长度。不选当前项直接递归下一项；若当前掩码与 mask 无交集，也可以选择它，新增长度后继续搜索，取两者最大值。

    解题步骤

    1. 逐字符串构建掩码，发现自身重复就剔除。
    2. 从 dfs(0,0) 开始。
    3. 先计算不选当前项的结果。
    4. 无字符冲突时，再比较选择当前项的结果；没有候选时返回新增长度 0。

    示例：[un,iq,ue] 中，un 与 ue 都含 u，不能同时选。可以选 un+iq，也可以选 iq+ue，最大长度均为 4。字符串 aa 自身重复，应在搜索前排除。 [aa,bc] 中只能选择 bc，答案为 2。

    代码实现

    class Solution {
    public int maxLength(List<String> arr) {
        List<Integer> masks = new ArrayList<>();
        List<Integer> lens = new ArrayList<>();

        for (String s : arr) {
            int mask = 0;
            boolean ok = true;

            for (int i = 0; i < s.length(); i++) {
                int bit = 1 << (s.charAt(i) - 'a');

                // 同一字符串内部有重复字母时，整个候选都不能选择。
                if ((mask & bit) != 0) {
                    ok = false;
                    break;
                }

                mask |= bit;
            }

            if (ok) {
                masks.add(mask);
                lens.add(s.length());
            }
        }

        return dfs(masks, lens, 0, 0);
    }

    // 返回剩余候选还能新增的长度，不包含当前 mask 已有部分。
    private int dfs(List<Integer> masks, List<Integer> lens, int idx, int mask) {
        if (idx == masks.size()) {
            return 0;
        }

        // 不选当前项始终合法，作为当前最优结果的初值。
        int best = dfs(masks, lens, idx + 1, mask);

        int next = masks.get(idx);

        // 无交集才允许选择；按值传入新掩码，无需手动恢复。
        if ((mask & next) == 0) {
            best = Math.max(best, lens.get(idx) + dfs(masks, lens, idx + 1, mask | next));
        }

        return best;
    }
}

    func maxLength(arr []string) int {
    masks := make([]int, 0)
    lens := make([]int, 0)

    for _, s := range arr {
        mask := 0
        ok := true
        for i := 0; i < len(s); i++ {
            bit := 1 << (s[i] - 'a')
            // 同一字符串内部有重复字母时，整个候选都不能选择。
            if mask&bit != 0 {
                ok = false
                break
            }
            mask |= bit
        }
        if ok {
            masks = append(masks, mask)
            lens = append(lens, len(s))
        }
    }

    return dfs(masks, lens, 0, 0)
}

// 返回剩余候选还能新增的长度，不包含当前 mask 已有部分。
func dfs(masks []int, lens []int, idx int, mask int) int {
    if idx == len(masks) {
        return 0
    }

    // 不选当前项始终合法，作为当前最优结果的初值。
    best := dfs(masks, lens, idx+1, mask)

    next := masks[idx]
    // 无交集才允许选择；按值传入新掩码，无需手动恢复。
    if mask&next == 0 {
        val := lens[idx] + dfs(masks, lens, idx+1, mask|next)
        if val > best {
            best = val
        }
    }
    return best
}

    复杂度分析

    • 时间复杂度：设有效候选数为 m、输入总字符数为 L，时间为 $O(L+2^m)$。
    • 空间复杂度：$O(m+1)$，保存有效掩码、长度和递归状态；没有有效候选时仍有常数开销。

    关键点总结

    [!green]

    • 返回新增长度，不重复计算 mask 已代表的字符。
    • 用 (mask & next)==0 判断无冲突，用 OR 合并集合。
    • mask 按值传递，返回后不需要再手动撤销位。

    易错点总结

    [!yellow]

    • 没有剔除自身重复串：aa 的掩码仅一位，却不能作为合法字符串选择。
    • 只搜索选择分支：较早的小串可能阻挡后面更长的候选，必须允许跳过。
    • 终点返回已选总长度：和外层逐项累加叠加后会重复计数。
    • 共用可变 mask 却不恢复：一个分支的已用字符会污染其他分支。
