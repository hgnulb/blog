    题目描述

    ✅ 1012. 至少有 1 位重复的数字

    题意分析

    统计 1 到 n 中十进制数位存在重复的整数。先求数位全部不同的正整数数量，再用 n 减去它。

    解法：数位 DP 计数

    核心思路

    [!blue]
    数位 DP 构造无重复的数。 dfs(pos, mask, tight) 表示当前位置为 pos、已使用数字集合为 mask、是否仍贴着 n 的上界时，剩余位置有多少种合法填法。

    mask 的第 d 位记录数字 d 是否已经使用。没有开始有效数字时，选到的 0 只是前导零，不写入 mask；开始之后，每一位都必须使用尚未出现的数字。

    tight 为真时，本位不能超过 n 的对应位；本位选小后，后续可自由取 0 到 9。只按 pos、mask 缓存自由状态，避免与受限状态混用。走到末尾计为一种构造，其中全前导零路径代表数字 0，做补集前要排除。

    解题步骤

    1. 把 n 转为数位序列，初始化记忆化表为 -1。
    2. 枚举当前位，处理前导零或加入一个尚未使用的数字。
    3. 按当前是否贴上界、所选数字是否等于上界，更新 tight。
    4. 缓存自由状态。返回 n-(dfs(0,0,true)-1)。

    示例：n=20 时，构造出的无重复数字为 0..9、10,12..19 和 20，共 20 个。排除 0 后有 19 个正整数，因此重复数字数量为 20-19=1，即 11。 n=210 时，前缀 12 与 21 的 mask 相同，但后者末位只能取 0，前者已经自由；二者不能共用省略 tight 的缓存。

    代码实现

    class Solution {
    private char[] digits;
    private int[][] memo;

    public int numDupDigitsAtMostN(int n) {
        digits = String.valueOf(n).toCharArray();
        memo = new int[digits.length][1 << 10];

        for (int[] row : memo) {
            Arrays.fill(row, -1);
        }

        // 递归包含数字 0，先扣除它，再用补集得到重复数字的数量。
        int uniquePositive = dfs(0, 0, true) - 1;

        return n - uniquePositive;
    }

    private int dfs(int pos, int mask, boolean tight) {
        if (pos == digits.length) {
            return 1;
        }

        // 只缓存不受上界约束的状态，避免混用两种枚举范围。
        if (!tight && memo[pos][mask] != -1) {
            return memo[pos][mask];
        }

        int limit = tight ? digits[pos] - '0' : 9;
        int ways = 0;

        for (int d = 0; d <= limit; d++) {
            boolean nextTight = tight && d == limit;

            // 前导零不是真实数位，不占用数字 0 的掩码。
            if (mask == 0 && d == 0) {
                ways += dfs(pos + 1, 0, nextTight);
                continue;
            }

            // 有效数位只能使用一次，掩码记录已使用的数字。
            int bit = 1 << d;

            if ((mask & bit) == 0) {
                ways += dfs(pos + 1, mask | bit, nextTight);
            }
        }

        if (!tight) {
            memo[pos][mask] = ways;
        }

        return ways;
    }
}

    import "strconv"

func numDupDigitsAtMostN(n int) int {
    digits := strconv.Itoa(n)
    memo := make([][]int, len(digits))
    for i := range memo {
        memo[i] = make([]int, 1<<10)
        for mask := range memo[i] {
            memo[i][mask] = -1
        }
    }

    var dfs func(pos, mask int, tight bool) int
    dfs = func(pos, mask int, tight bool) int {
        if pos == len(digits) {
            return 1
        }
        // 只缓存不受上界约束的状态，避免混用两种枚举范围。
        if !tight && memo[pos][mask] != -1 {
            return memo[pos][mask]
        }

        limit := 9
        if tight {
            limit = int(digits[pos] - '0')
        }

        ways := 0
        for d := 0; d <= limit; d++ {
            nextTight := tight && d == limit
            // 前导零不是真实数位，不占用数字 0 的掩码。
            if mask == 0 && d == 0 {
                ways += dfs(pos+1, 0, nextTight)
                continue
            }

            // 有效数位只能使用一次，掩码记录已使用的数字。
            bit := 1 << d
            if mask&bit == 0 {
                ways += dfs(pos+1, mask|bit, nextTight)
            }
        }

        if !tight {
            memo[pos][mask] = ways
        }
        return ways
    }

    // 递归包含数字 0，先扣除它，再用补集得到重复数字的数量。
    uniquePositive := dfs(0, 0, true) - 1
    return n - uniquePositive
}

    复杂度分析

    • 时间复杂度：设十进制位数为 L，时间为 $O(L\cdot2^{10}\cdot10)$，每个状态最多枚举 10 个数字。
    • 空间复杂度：$O(L\cdot2^{10})$，用于记忆化表；递归深度为 L。

    关键点总结

    [!green]

    • 补集把重复条件转成“每个数字最多使用一次”。
    • mask=0 可以代表尚未开始：有效首位非零，开始后掩码不会再变回 0。
    • 自由状态可复用，受限状态和自由状态不能共用相同缓存键。

    易错点总结

    [!yellow]

    • 前导零占用掩码：会把补齐长度的 0 当成真实数字，漏掉合法构造。
    • 忘记排除数字 0：n=20 会错误算成 0 个重复数。
    • 一旦选小仍继续限制后续数位：会漏掉本应允许任意数字的后缀。
    • 把受限结果直接缓存到 pos、mask：同一掩码的不同前缀可能有不同上界。
