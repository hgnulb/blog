    题目描述

    ✅ 1105. 填充书架

    题意分析

    按原顺序把书放到若干层书架，每层总宽度不能超过 shelfWidth，层高由该层最高的书决定。求所有层高度之和的最小值。

    解法：动态规划状态转移

    核心思路

    [!blue]
    用前缀 DP 枚举最后一层。 dp[i] 表示前 i 本书的最小总高度。若最后一层是 books[j..i-1]，候选高度就是 dp[j]+这一层的最高书高。

    从右向左逐本加入最后一层，同时维护总宽度和最大高度。宽度一旦超限，再向左只会更宽，可以直接停止。每一种合法最后层起点都被枚举，前面的书使用已算出的最优结果。

    解题步骤

    1. 令 dp[0]=0。
    2. 计算 dp[i] 时，先让最后一本单独一层，得到合法初值。
    3. 从 i-2 向左增加书；先检查宽度，再更新层高和候选总高度。
    4. 返回 dp[n]。

    示例：books=[[1,3],[2,4],[3,2]]、shelfWidth=4：前两本同层高 4，第三本另起一层高 2，总高为 6。不能总把当前层塞满：[[1,1],[2,3],[2,3],[1,1]]、宽度 4，分为 1 本、2 本、1 本三层只需高 5，塞满两层反而为 6。

    代码实现

    class Solution {
    public int minHeightShelves(int[][] books, int shelfWidth) {
        int n = books.length;
        // dp[i] 表示前 i 本书的最小总高度，dp[0] 对应空前缀。
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            int width = books[i - 1][0];
            int height = books[i - 1][1];
            // 先让最后一本单独成层，作为必定合法的初值。
            dp[i] = dp[i - 1] + height;

            for (int j = i - 2; j >= 0; j--) {
                width += books[j][0];
                // 向左扩展只会更宽，超限后可停止枚举。
                if (width > shelfWidth) {
                    break;
                }
                height = Math.max(height, books[j][1]);
                // 最后一层从 j 开始，前 j 本接 dp[j]，本层只加最高书高。
                dp[i] = Math.min(dp[i], dp[j] + height);
            }
        }
        return dp[n];
    }
}

    func minHeightShelves(books [][]int, shelfWidth int) int {
	n := len(books)
	// dp[i] 表示前 i 本书的最小总高度，dp[0] 对应空前缀。
	dp := make([]int, n+1)
	for i := 1; i <= n; i++ {
		width := books[i-1][0]
		height := books[i-1][1]
		// 先让最后一本单独成层，作为必定合法的初值。
		dp[i] = dp[i-1] + height

		for j := i - 2; j >= 0; j-- {
			width += books[j][0]
			// 向左扩展只会更宽，超限后可停止枚举。
			if width > shelfWidth {
				break
			}
			if books[j][1] > height {
				height = books[j][1]
			}
			// 最后一层从 j 开始，前 j 本接 dp[j]，本层只加最高书高。
			if dp[j]+height < dp[i] {
				dp[i] = dp[j] + height
			}
		}
	}
	return dp[n]
}

    复杂度分析

    • 时间复杂度：$O(n²)$，每个末端最多向左枚举 n 本书。
    • 空间复杂度：$O(n)$，保存前缀最优高度。

    关键点总结

    [!green]

    • 顺序固定，每一层一定是一段连续区间。
    • 单本书合法，所以可以用最后一本单独成层作为初值。
    • 宽度与高度都增量维护，不为每个候选重新扫描。
    • 最后一层从 j 开始，前面恰好有 j 本书，因此连接 dp[j]。

    易错点总结

    [!yellow]

    • 把层高当成高度之和：同层书的高度取最大值。
    • 超宽后仍更新答案：会把非法的一层纳入结果。
    • 前缀连接错下标：最后一层从 j 开始，前面恰有 j 本，应接 dp[j]。
