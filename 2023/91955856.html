    LeetCode 345. 反转字符串中的元音字母

    2023-05-27 HGNULB 约 4 分钟
    文章信息 9 个分类 · 2 个标签
    分类
    LeetCode CodeTop 简单 未解决 2-5 字节 阿里 华为 LeetCode 75
    标签
    字符串 双指针

    题目描述

    ✅ 345. 反转字符串中的元音字母

    题意分析

    只反转字符串中的元音出现次序，其余字符位置保持不变，大小写元音都要识别。

    解法：左右指针交换元音

    核心思路

    [!blue]

    两端指针分别跳过非元音，找到最左和最右尚未处理元音后交换，再向内继续。这样完成的两端不再参与后续处理，非元音始终不被写动。

    输入字符串不可变，先转换为可修改数组，最后转回字符串。元音判断只识别指定的十个字符，标点和数字不是元音。

    解题步骤

    • 从两端寻找元音，查字符前先检查界限。
    • 还有两个不同位置时交换，再向内移动。
    • 指针相遇后返回。

    leetcode→leotcede；aA→Aa 说明大写元音也参与交换。

    代码实现

    class Solution {
    // 左右指针分别向中间寻找下一个元音，两个指针都停在元音上时再交换。
    public String reverseVowels(String s) {
        char[] chars = s.toCharArray();
        int left = 0;
        int right = chars.length - 1;

        // 两端之外的元音已就位，非元音位置始终不改动
        while (left < right) {
            while (left < right && !isVowel(chars[left])) {
                left++;
            }

            while (left < right && !isVowel(chars[right])) {
                right--;
            }

            if (left < right) {
                char swapValue = chars[left];

                chars[left] = chars[right];
                chars[right] = swapValue;
            }

            left++;
            right--;
        }

        return new String(chars);
    }

    private boolean isVowel(char ch) {
        return "aeiouAEIOU".indexOf(ch) >= 0;
    }
}

    func reverseVowels(s string) string {
    // 左右指针分别向中间寻找下一个元音，两个指针都停在元音上时再交换。
    chars := []byte(s)
    left, right := 0, len(chars)-1

    // 两端之外的元音已就位，非元音位置始终不改动
    for left < right {
        for left < right && !isVowel(chars[left]) {
            left++
        }
        for left < right && !isVowel(chars[right]) {
            right--
        }

        if left < right {
            chars[left], chars[right] = chars[right], chars[left]
        }
        left++
        right--
    }

    return string(chars)
}

func isVowel(ch byte) bool {
    switch ch {
    case 'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U':
        return true
    default:
        return false
    }
}

    复杂度分析

    • 时间复杂度：$O(n)$，每个指针单向移动。
    • 空间复杂度：$O(n)$，字符缓冲与结果转换。

    关键点总结

    [!green]

    • 交换发生在元音位置之间，其他位置不动。
    • 大小写字符各自保留原字符，不做统一转小写。

    易错点总结

    [!yellow]

    • 只识别小写会漏掉 aA 中的 A。
    • 将所有非辅音都当元音，会错误移动符号。
    • 寻找时不检查指针界限，全无元音时会越界。
