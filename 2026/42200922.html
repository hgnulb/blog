    LeetCode 340. 至多包含 K 个不同字符的最长子串

    题目描述

    ✅ 340. 至多包含 K 个不同字符的最长子串

    题意分析

    求包含至多 k 种不同字符的最长连续子串长度。限制的是字符种类，不是字符总数，也不是每种字符的频次。

    解法：滑动窗口维护字符种类

    核心思路

    [!blue]

    右端加入字符后，种类超限就从左端持续移出，恢复合法再更新答案。超限窗口继续向右扩展不会减少种类，只能缩左边，因此两个指针都无需回退。

    哈希表仅保留正计数，降为零时删键，表大小才能等于窗口种类数。种类恰好等于 k 仍合法；k=0 时直接返回零。

    解题步骤

    • k == 0 时直接返回 0；初始化计数表、左端点和答案。
    • 右端点逐字符扩张，并将新字符计数加一。
    • 当表中字符种类超过 $k$ 时，循环移动左端点；移出字符的计数降为 0 就删除该键。
    • 窗口恢复合法后，用 right - left + 1 更新最大长度。

    例如 s = "eceba"、k = 2：窗口先扩到 "ece"，答案更新为 3；加入 b 后种类数变成 3，连续移出 e、c 才恢复合法。之后加入 a 也需要收缩，最终答案仍为 3。

    代码实现

    class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        if (k == 0) {
            return 0;
        }

        Map<Character, Integer> count = new HashMap<>();
        int left = 0;
        int ans = 0;

        for (int right = 0; right < s.length(); right++) {
            char in = s.charAt(right);

            count.put(in, count.getOrDefault(in, 0) + 1);

            while (count.size() > k) {
                char out = s.charAt(left++);

                count.put(out, count.get(out) - 1);

                if (count.get(out) == 0) {
                    // 只保留正频次键，表大小才能等于窗口内的字符种类。
                    count.remove(out);
                }
            }

            // 窗口合法时才能更新最长长度。
            ans = Math.max(ans, right - left + 1);
        }

        return ans;
    }
}

    func lengthOfLongestSubstringKDistinct(s string, k int) int {
    if k == 0 {
        return 0
    }

    count := make(map[byte]int)
    left := 0
    ans := 0
    for right := 0; right < len(s); right++ {
        count[s[right]]++
        for len(count) > k {
            out := s[left]
            left++
            count[out]--
            if count[out] == 0 {
                // 只保留正频次键，表大小才能等于窗口内的字符种类。
                delete(count, out)
            }
        }
        // 哈希表大小就是当前窗口不同字符数量。
        if right-left+1 > ans {
            ans = right - left + 1
        }
    }
    return ans
}

    复杂度分析

    • 时间复杂度：$O(n)$。左右指针各最多移动 $n$ 次，哈希表操作均摊为 $O(1)$。
    • 空间复杂度：$O(k+1)$。哈希表在扩张瞬间最多保存 $k + 1$ 种字符，收缩结束后不超过 $k$ 种。

    关键点总结

    [!green]

    • 可变窗口的成立条件是「非法性单调」：区间越长字符种类越多，越界之后只能靠缩左端恢复，这决定了右端点无需回退。
    • 计数减到 0 必须删键，这是 count.size() 能代表不同字符数的前提，也是本题最容易漏的一行。
    • 更新答案的时机必须在收缩之后，保证参与取最大值的一定是合法窗口。

    易错点总结

    [!yellow]

    • 计数归零却不删键，表大小无法减少，收缩循环可能越界。
    • 收缩前更新答案，会把含过多字符种类的非法窗口计入。
    • 收缩条件用 >=k 会排除恰好含 k 种的合法窗口，正确条件为 >k。
    • 频次之和是字符总数，哈希表大小才是不同字符种类数。
    • 忽略连续性、直接选全局高频字符，无法得到合法子串。
