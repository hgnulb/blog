    题目描述

    ✅ 1190. 反转每对括号间的子串

    题意分析

    逐层反转括号中的内容，返回不含括号的结果。用配对下标和读取方向模拟反转，无需反复搬动字符。

    解法：括号配对后改变遍历方向

    核心思路

    [!blue]

    先用栈记录每对括号的双向配对。随后字母按当前方向输出，遇到任一括号就跳到配对端、反转方向，再统一前进一步。

    每对括号在进入、退出其区间时各触发一次跳转，每个字母只输出一次。嵌套通过方向切换自然处理，配对位置决定各段的读取范围。

    解题步骤

    • 扫描建立双向 pair。
    • 从最左向右开始，遇字母输出。
    • 遇括号跳转并掉头，分支后统一按新方向移动。

    (u(love)i) 先从外层右端读 i，进入内层后正向读 love，再读 u，得到 iloveu。 (ab)(cd) 得 badc，(abcd) 得 dcba，虽然各字母都在一层括号里，最终位置仍取决于具体配对范围。

    代码实现

    class Solution {
    public String reverseParentheses(String s) {
        int n = s.length();
        int[] pair = new int[n];
        int[] stack = new int[n];
        int top = 0;

        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);

            if (ch == '(') {
                stack[top++] = i;
            } else if (ch == ')') {
                int left = stack[--top];

                // 配对双向记录，反向遇到右括号时也能跳转。
                pair[left] = i;
                pair[i] = left;
            }
        }

        StringBuilder ans = new StringBuilder();
        int idx = 0;
        int dir = 1;

        while (idx >= 0 && idx < n) {
            char ch = s.charAt(idx);

            if (ch == '(' || ch == ')') {
                // 跳到另一端再掉头，改变读取方向来表达反转。
                idx = pair[idx];
                dir = -dir;
            } else {
                ans.append(ch);
            }

            // 跳转后仍要迈一步，不能停在配对括号上。
            idx += dir;
        }

        return ans.toString();
    }
}

    func reverseParentheses(s string) string {
    n := len(s)
    pair := make([]int, n)
    stack := make([]int, 0, n)

    for i := 0; i < n; i++ {
        if s[i] == '(' {
            stack = append(stack, i)
        } else if s[i] == ')' {
            left := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            // 配对双向记录，反向遇到右括号时也能跳转。
            pair[left] = i
            pair[i] = left
        }
    }

    res := make([]byte, 0, n)
    idx := 0
    dir := 1
    for idx >= 0 && idx < n {
        if s[idx] == '(' || s[idx] == ')' {
            // 跳到另一端再掉头，改变读取方向来表达反转。
            idx = pair[idx]
            dir = -dir
        } else {
            res = append(res, s[idx])
        }
        // 跳转后仍要迈一步，不能停在配对括号上。
        idx += dir
    }

    return string(res)
}

    复杂度分析

    • 时间复杂度：$O(n)$，配对一遍，主遍历按字母与括号对线性推进。
    • 空间复杂度：$O(n)$，配对表、栈与结果缓冲。

    关键点总结

    [!green]

    • 跳转后的落点仍是括号，必须再走一步进入或离开区间。
    • 双向配对同时支持从左右两侧进入。

    易错点总结

    [!yellow]

    • 只跳转不掉头，会跳过需要读取的内容。
    • 跳转后直接继续而不移动，会在两个括号之间反复跳。
    • 只记左括号到右括号，反向进入时无法找到配对端。
