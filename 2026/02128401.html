    题目描述

    ✅ 515. 在每个树行中找最大值

    题意分析

    每层取一个最大节点值，按从上到下的层次返回。节点可以为负数，空树没有任何层。

    解法：层序遍历

    核心思路

    [!blue]

    层序遍历开始处理一层时，冻结当前未处理节点数量。这一轮只取出这些节点，新加入的孩子留到下一层。

    最大值在每层重新初始化为合法下界，完成整层比较后再追加一次结果，避免混层和漏掉负数。

    解题步骤

    • 根入队，空树直接返回空结果。
    • 记录本层数量，最大值重置。
    • 只处理本层节点，同时将非空孩子入队。
    • 整层结束后追加最大值。

    根一，第二层三、二，第三层五、三、九，返回 [1,3,9]；根负五、左孩子负九则返回 [-5,-9]。

    代码实现

    // 每一层扫描节点值，取最大值加入结果。
class Solution {
    public List<Integer> largestValues(TreeNode root) {
        List<Integer> res = new ArrayList<>();

        if (root == null) {
            return res;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();

        queue.offer(root);

        while (!queue.isEmpty()) {
            // 冻结本层数量，新入队孩子留到下一层
            int size = queue.size();
            // 下界允许整层都是负数，也允许真实最小整数
            int max = Integer.MIN_VALUE;

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();

                max = Math.max(max, node.val);

                if (node.left != null) {
                    queue.offer(node.left);
                }

                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            res.add(max);
        }

        return res;
    }
}

    // 每一层扫描节点值，取最大值加入结果。
func largestValues(root *TreeNode) []int {
    res := make([]int, 0)
    if root == nil {
        return res
    }

    queue := []*TreeNode{root}
    for head := 0; head < len(queue); {
        // 冻结本层数量，新入队孩子留到下一层
        size := len(queue) - head
        // 下界允许整层都是负数，也允许真实最小整数
        maxVal := -1 << 31

        for i := 0; i < size; i++ {
            node := queue[head]
            head++

            if node.Val > maxVal {
                maxVal = node.Val
            }

            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        res = append(res, maxVal)
    }

    return res
}

    复杂度分析

    • 时间复杂度：$O(n)$，每个节点访问一次。
    • 空间复杂度：最坏 $O(n)$；Java 活动队列为 $O(w)$，Go 当前切片保留已处理项，累计为 $O(n)$，w 为最大层宽。

    关键点总结

    [!green]

    • 本层数量在开始时固定，不能随孩子入队变化。
    • 下界本身也可以是合法答案，不要求最大值一定被改大。

    易错点总结

    [!yellow]

    • 最大值从零开始，会错误处理全负数的一层。
    • 内层条件使用变化中的队列长度，会将不同层混在一起。
    • 每处理一个节点就追加，会使一层出现多个结果。
