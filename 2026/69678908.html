    题目描述

    ✅ 96. 不同的二叉搜索树

    题意分析

    用 1..n 这些有序键组成不同的二叉搜索树，求结构数量，不实际生成所有树。选择根后，哪些键属于左、右子树已经确定，子问题只需记录节点数量。

    解法：Catalan 动态规划

    核心思路

    [!blue]

    dp[nodes] 表示给定数量有序键的结构数。选择第 root 个键时，左右节点数为 root - 1 和 nodes - root，两侧可以独立组合，因此相乘；不同根的方案再相加。

    空子树是一种合法选择，所以 dp[0] = 1。n = 3 时三种根位置分别贡献 2、1、2，合计 5。若把空子树计成零，所有一侧为空的合法结构都会被漏掉。

    解题步骤

    1. 建立 dp[0..n]，令 dp[0] = 1。
    2. 按 nodes = 1..n 递增计算，保证转移需要的小规模答案已就绪。
    3. 枚举根的位置 root = 1..nodes，累加 dp[root-1] * dp[nodes-root]。
    4. 返回 dp[n]。

    示例：n = 3 时，根分别在第 1、2、3 位，贡献为 dp[0]dp[2] + dp[1]dp[1] + dp[2]dp[0] = 2+1+2 = 5。

    边界检查：根为最小值或最大值时，一侧为空；正因为 dp[0] = 1，这些合法结构才不会被乘成 0。

    代码实现

    class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        // 空子树也有一种构造，作为左右组合计数的乘法单位。
        dp[0] = 1;

        for (int nodes = 1; nodes <= n; nodes++) {
            for (int root = 1; root <= nodes; root++) {
                // 固定根后左右构造独立相乘，不同根的情况再相加。
                dp[nodes] += dp[root - 1] * dp[nodes - root];
            }
        }
        return dp[n];
    }
}

    func numTrees(n int) int {
    dp := make([]int, n+1)
    // 空子树也有一种构造，作为左右组合计数的乘法单位。
    dp[0] = 1

    for nodes := 1; nodes <= n; nodes++ {
        for root := 1; root <= nodes; root++ {
            // 固定根后左右构造独立相乘，不同根的情况再相加。
            dp[nodes] += dp[root-1] * dp[nodes-root]
        }
    }
    return dp[n]
}

    复杂度分析

    • 时间复杂度：$O(n^2)$，总转移次数为 $1+2+\cdots+n$。
    • 空间复杂度：$O(n)$，保存 n+1 个规模的答案。

    关键点总结

    [!green]

    • 只求数量时做计数 DP，不要构造指数级的树集合。
    • 不同根的方案互斥，所以求和；左右子树独立，所以相乘。
    • dp[0] = 1 表示一种「空的选择」，不是存在一个空节点。

    易错点总结

    [!yellow]

    • 将 dp[0] 留为默认值 0：所有包含空子树的乘积都会归零。
    • 把左右方案相加，或把不同根的贡献相乘：混淆了独立组合与互斥分类。
    • 写成赋值而不是累加：只会保留最后一个根位置的贡献。
    • 将左子树规模写成 root：根本身不属于子树，正确值是 root-1。
    • 擅自取模：本题要求精确答案，且约束保证结果在 32 位有符号整数内。
