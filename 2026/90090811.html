    题目描述

    ✅ 1049. 最后一块石头的重量 II

    题意分析

    每次任选两块石头碰撞，产生重量差，求最终最小剩余重量。选择顺序由我们决定，不能固定每次撞最重的两块。

    解法：0/1 背包接近半和

    核心思路

    [!blue]

    任何碰撞结果展开后，都是原重量带正负号的总和绝对值，因此对应两组重量差。最优分组差也可实现：不断跨两组碰撞，把残块放回较重的一侧，差值保持不变。

    若最终一侧还剩至少两块，最小残块 r 小于总差 D；将它所代表的原石符号整体翻转，会得到更小的 |D-2r|，与最优分组矛盾。因此最优差能够通过碰撞得到。

    总重为 S，只需找不超过 S/2 的最大子集和 x，答案为 S-2x。这是每块只能选一次的零一背包，容量倒序更新避免重复选当前石头。

    解题步骤

    • 求总重与向下取整的一半容量。
    • 每块石头依次处理，容量从大到小更新最大可装重量。
    • 返回总重减两倍最佳半组和。

    [2,7,4,1,8,1] 总重二十三，可选七加四为十一，另一组十二，最小差一。

    代码实现

    class Solution {
    public int lastStoneWeightII(int[] stones) {
        int sum = 0;

        for (int stone : stones) {
            sum += stone;
        }

        int target = sum / 2;
        // 每个容量记录不超过它的最大可达重量，未必恰好装满
        int[] dp = new int[target + 1];

        for (int stone : stones) {
            // 容量倒序保证每块石头只选一次
            for (int cap = target; cap >= stone; cap--) {
                dp[cap] = Math.max(dp[cap], dp[cap - stone] + stone);
            }
        }

        // 另一组重量是总和减所选组，最终取两组差
        return sum - 2 * dp[target];
    }
}

    func lastStoneWeightII(stones []int) int {
    sum := 0
    for _, stone := range stones {
        sum += stone
    }

    target := sum / 2
    // 每个容量记录不超过它的最大可达重量，未必恰好装满
    dp := make([]int, target+1)
    for _, stone := range stones {
        // 容量倒序保证每块石头只选一次
        for cap := target; cap >= stone; cap-- {
            candidate := dp[cap-stone] + stone
            if candidate > dp[cap] {
                dp[cap] = candidate
            }
        }
    }
    // 另一组重量是总和减所选组，最终取两组差
    return sum - 2*dp[target]
}

    复杂度分析

    • 时间复杂度：$O(n(T+1))$，n 为石头数量、T 为向下取整的半和容量，包含零容量情况。
    • 空间复杂度：$O(T+1)$，一维容量表。

    关键点总结

    [!green]

    • 容量状态表示不超过容量的最大子集和，不要求恰好装满。
    • 倒序保证旧状态尚未使用当前石头。

    易错点总结

    [!yellow]

    • 正序更新会重复使用一块石头。
    • 容量向上取整后仍返回 S-2x，可能得到负数。
    • 只求总重减一组和，得到的是另一组重量而非两组差。
