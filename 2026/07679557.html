    题目描述

    ✅ 347. 前 K 个高频元素

    题意分析

    返回出现频次最高的 k 个不同元素。先统计频次，再按频次分桶；桶下标是出现次数，桶中存放具有该次数的不同元素。

    解法：哈希计数 + 频率桶

    核心思路

    [!blue]

    频次最多为原数组长度 n，建立 n + 1 个桶后，从高频桶向低频桶收集，恰好得到 k 个元素便停止。相同频次的元素放在同一桶，桶内输出顺序不影响结果。

    题目保证唯一的是被选中的元素集合，不要求这些元素的频次都不同。[1,1,1,2,2,3]、k = 2 先取频次三的 1，再取频次二的 2，不必对所有不同元素完整排序。

    解题步骤

    • 遍历 nums，用哈希表统计每个元素的出现次数。
    • 创建长度为 n + 1 的桶数组；最大频次可能是 n，所以必须保留下标 n。
    • 遍历计数表，将元素放入 buckets[frequency]。同频元素可能有多个，因此每个桶是列表。
    • 从频次 n 向 1 倒序扫描，将非空桶中的元素加入结果，收满 k 个立即结束。
    • 示例：[1,1,1,2,2,3], k=2 的计数是 {1:3, 2:2, 3:1}，对应 bucket[3]=[1]、bucket[2]=[2]、bucket[1]=[3]；倒序先取 1，再取 2，得到 [1,2]。

    代码实现

    class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();

        for (int num : nums) {
            freq.put(num, freq.getOrDefault(num, 0) + 1);
        }

        List<Integer>[] buckets = new ArrayList[nums.length + 1];

        for (Map.Entry<Integer, Integer> entry : freq.entrySet()) {
            int count = entry.getValue();

            if (buckets[count] == null) {
                buckets[count] = new ArrayList<>();
            }

            buckets[count].add(entry.getKey());
        }

        int[] res = new int[k];
        int idx = 0;

        for (int count = buckets.length - 1; count >= 1 && idx < k; count--) {
            if (buckets[count] == null) {
                continue;
            }

            // 从高频桶向低频桶收集，先拿到的就是高频元素。
            for (int num : buckets[count]) {
                res[idx++] = num;

                if (idx == k) {
                    break;
                }
            }
        }

        return res;
    }
}

    func topKFrequent(nums []int, k int) []int {
    freq := make(map[int]int)
    for _, num := range nums {
        freq[num]++
    }

    buckets := make([][]int, len(nums)+1)
    for num, count := range freq {
        buckets[count] = append(buckets[count], num)
    }

    res := make([]int, 0, k)
    for count := len(buckets) - 1; count >= 1 && len(res) < k; count-- {
        // 高频桶优先输出，桶内顺序不影响题意。
        for _, num := range buckets[count] {
            res = append(res, num)
            if len(res) == k {
                break
            }
        }
    }
    return res
}

    复杂度分析

    • 时间复杂度：$O(n)$。计数、入桶和倒序扫描合计为 $O(n+m+n)$，其中不同元素数 $m\le n$。
    • 空间复杂度：$O(n)$。哈希表、桶数组及桶内元素总量都不超过线性规模；不计返回结果仍为 $O(n)$。

    关键点总结

    [!green]

    • 桶的下标是频次而不是元素值；负数元素也能正常处理。
    • 频次值域 [1,n] 是线性解法的突破口，本质是用数组下标代替比较。
    • 返回顺序任意，同频桶内无需额外排序。

    易错点总结

    [!yellow]

    • 桶长度少一位：[7,7,7], k=1 的频次为 3，桶必须开成 n+1 才能访问下标 n。
    • 未跳过 Java 的空桶：未初始化的 buckets[count] 是 null，直接遍历会触发空指针。
    • 把元素值当桶下标：[-1,-1,3] 会访问负下标；桶索引必须是频次。
    • 收满 k 个后仍继续写结果：外层循环也要受 idx < k 限制，避免越界或返回多余元素。
