    题目描述

    ✅ 992. K 个不同整数的子数组

    题意分析

    统计不同整数恰好 k 种的连续子数组。重复值影响窗口频次，同一内容在不同下标区间出现要分别计数。

    解法：前缀计数差法与滑动窗口

    核心思路

    [!blue]

    恰好 k 种的数量等于至多 k 种减去至多 k−1 种。只实现一个 atMost 窗口计数函数，两次独立调用。

    固定右端，收缩到种类数不超标的最小左端，此时从左端到右端的每个起点都合法，贡献为 right-left+1。

    解题步骤

    • 加入右端元素并增加频次。
    • 种类过多时循环移除左端，频次归零才删除键。
    • 收缩完成后累加窗口长度。
    • 两个上界的结果相减。

    [1,2,1,2,3] 中至多两种的逐端贡献为1、2、3、4、2，总计12；至多一种为5，答案7。

    代码实现

    class Solution {
    public int subarraysWithKDistinct(int[] nums, int k) {
        return atMost(nums, k) - atMost(nums, k - 1);
    }

    private int atMost(int[] nums, int k) {
        if (k <= 0) {
            return 0;
        }

        Map<Integer, Integer> count = new HashMap<>();
        int left = 0;
        int answer = 0;

        for (int right = 0; right < nums.length; right++) {
            count.put(nums[right], count.getOrDefault(nums[right], 0) + 1);
            while (count.size() > k) {
                count.put(nums[left], count.get(nums[left]) - 1);
                if (count.get(nums[left]) == 0) {
                    // 最后一个副本离开窗口时，种类才减少。
                    count.remove(nums[left]);
                }
                left++;
            }
            // 合法窗口内每个起点都对应一个以当前右端结尾的子数组。
            answer += right - left + 1;
        }

        return answer;
    }
}

    func subarraysWithKDistinct(nums []int, k int) int {
    if k <= 0 {
        return 0
    }
    return atMost(nums, k) - atMost(nums, k-1)
}

func atMost(nums []int, k int) int {
    count := make(map[int]int)
    left := 0
    answer := 0

    for right, v := range nums {
        count[v]++
        for len(count) > k {
            count[nums[left]]--
            if count[nums[left]] == 0 {
                // 最后一个副本离开窗口时，种类才减少。
                delete(count, nums[left])
            }
            left++
        }
        // 合法窗口内每个起点都对应一个以当前右端结尾的子数组。
        answer += right - left + 1
    }

    return answer
}

    复杂度分析

    • 时间复杂度：期望 $O(n)$，两次扫描各自的左右指针都只前进。
    • 空间复杂度：$O(\min(n,k)+1)$，包含加入新种类但尚未收缩的瞬间。

    关键点总结

    [!green]

    • 频次表记录副本数量，键数才是种类数。
    • 至多零种的非空子数组数量为零。

    易错点总结

    [!yellow]

    • 用 Set 无法判断移除一个副本后该值是否仍在窗口内。
    • 只收缩一次可能仍有重复副本挡在左端，应使用循环。
    • 在窗口合法前计数，会把跨越超标种类的区间算进去。
