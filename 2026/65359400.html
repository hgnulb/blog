    题目描述

    ✅ 517. 超级洗衣机

    题意分析

    一排洗衣机每轮可同时转移衣服，但每台机器一轮最多送出一件。求让各机器衣服数相同的最少轮数；总数不能均分时返回 -1。

    解法：前缀净流量 + 并行瓶颈

    核心思路

    [!blue]
    同时找跨边流量和单机送出两个瓶颈。 设平均值为 avg，当前机器盈亏 diff=machines[i]-avg，扫描到 i 的前缀盈亏 balance 为前 i+1 台机器必须跨过右侧分界的净衣服数。跨边无论方向每轮至多通过一件，所以至少需要 |balance| 轮。

    一台机器一轮最多送出一件，因此正的 diff 也给出必要轮数；负的 diff 表示需要接收，不单独限制轮数。所有位置的 max( balance , diff) 的最大值就是答案，不能把各位置的流量相加。

    按各分界确定的净方向安排传送，相邻机器可以在同一轮一边接收、一边继续送出，形成流水线。若一个节点要同时向两侧送，其总送出量等于自身正盈余；只向一侧送时，其送出量不超过对应分界流量。因此按上述最大瓶颈轮数安排即可达到下界。

    解题步骤

    1. 计算衣服总数，不能被机器数整除就返回 -1。
    2. 求平均值，初始化前缀盈亏和答案为零。
    3. 从左到右计算 diff，累加到 balance。
    4. 每台更新答案为当前答案、 balance 、diff 的最大值。

    示例：[1,0,5] 的平均值为二，前缀盈亏依次为 -1、-3、0，最大跨边需求为三，答案三。[0,3,0] 的跨边需求最多一，但中间机器须送出两件，答案二。

    代码实现

    class Solution {
    public int findMinMoves(int[] machines) {
        int n = machines.length;
        int sum = 0;
        for (int x : machines) {
            sum += x;
        }
        if (sum % n != 0) {
            return -1;
        }

        int avg = sum / n;
        int answer = 0;
        int balance = 0;
        for (int x : machines) {
            int diff = x - avg;
            // 前缀盈亏决定这条相邻分界必须通过的净衣物数量。
            balance += diff;
            // 跨边流量看绝对值，单机瓶颈只看需要送出的正盈余。
            answer = Math.max(answer, Math.max(Math.abs(balance), diff));
        }
        return answer;
    }
}

    func findMinMoves(machines []int) int {
    n := len(machines)
    sum := 0
    for _, x := range machines {
        sum += x
    }
    if sum%n != 0 {
        return -1
    }

    avg := sum / n
    answer := 0
    balance := 0
    for _, x := range machines {
        diff := x - avg
        // 前缀盈亏决定这条相邻分界必须通过的净衣物数量。
        balance += diff
        // 跨边流量看绝对值，单机瓶颈只看需要送出的正盈余。
        answer = max(answer, max(abs(balance), diff))
    }
    return answer
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

    复杂度分析

    • 时间复杂度：$O(n)$，两次线性扫描。
    • 空间复杂度：$O(1)$，只保存总数、前缀盈亏与答案。

    关键点总结

    [!green]

    • 跨边的净流量由前缀盈亏唯一确定。
    • 一轮可以由多台同时送出，轮数取最紧瓶颈而非流量总和。
    • 机器的负盈亏代表接收需求；单机送出限制只由正盈亏形成。

    易错点总结

    [!yellow]

    • 总数不能整除仍继续计算：目标平均值不存在。
    • 只取前缀盈亏绝对值：[0,3,0] 会漏掉中间机器必须分两轮送出的限制。
    • 只取正盈余：[0,0,11,5] 的平均值为四，机器最大正盈余为七，但跨第二条分界需要八轮。
    • 把负盈亏也取绝对值作为单机瓶颈：接收可以来自两侧，不受一次只送一件的限制。
