    题目描述

    ✅ 1360. 日期之间隔几天

    题意分析

    把两个日期都转换成同一参考日之后的整数序号，取差的绝对值，就是相隔天数。

    解法：日期转天数序号

    核心思路

    [!blue]

    序号分为此前完整年份、当年此前完整月份和当前日号三部分。整年循环按该年份判断闰年，整月部分按日期所在年份处理二月。

    公历闰年条件是可被四百整除，或可被四整除但不可被一百整除。两个日期使用相同起点，公共偏移相减后抵消。

    解题步骤

    • 按固定位置解析年月日。
    • 累加参考年到前一年的天数。
    • 累加本年前几个月，跨二月时按闰年补一天。
    • 加日号，两个编号相减取绝对值。

    2019-12-31 到2020-01-15 相隔15天；2100-02-28 到2100-03-01 只隔一天。 2000-02-28 到2000-03-01 相隔两天，因为2000是闰年。

    代码实现

    class Solution {
    public int daysBetweenDates(String date1, String date2) {
        int days1 = countDays(date1);
        int days2 = countDays(date2);

        // 同一参考日起算的序号作绝对差，不依赖日期先后。
        return Math.abs(days1 - days2);
    }

    private int countDays(String date) {

        int year = Integer.parseInt(date.substring(0, 4));
        int month = Integer.parseInt(date.substring(5, 7));
        int day = Integer.parseInt(date.substring(8, 10));
        int[] monthDays = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

        int answer = 0;

        // 此前完整年份按各自的闰年状态累加。
        for (int y = 1971; y < year; y++) {
            if (isLeapYear(y)) {
                answer += 366;
            } else {
                answer += 365;
            }
        }

        for (int m = 1; m < month; m++) {
            answer += monthDays[m - 1];

            // 只有日期所在年为闰年且已经跨过二月，才补一天。
            if (m == 2 && isLeapYear(year)) {
                answer++;
            }
        }

        return answer + day;
    }

    private boolean isLeapYear(int year) {

        return year % 400 == 0 || (year % 4 == 0 && year % 100 != 0);
    }
}

    func daysBetweenDates(date1 string, date2 string) int {
    days1 := countDays(date1)
    days2 := countDays(date2)

    // 同一参考日起算的序号作绝对差，不依赖日期先后。
    if days1 > days2 {
        return days1 - days2
    }

    return days2 - days1
}

func countDays(date string) int {

    year := atoi(date[:4])
    month := atoi(date[5:7])
    day := atoi(date[8:])
    monthDays := []int{31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}

    answer := 0

    // 此前完整年份按各自的闰年状态累加。
    for y := 1971; y < year; y++ {
        if isLeapYear(y) {
            answer += 366
        } else {
            answer += 365
        }
    }

    for m := 1; m < month; m++ {
        answer += monthDays[m-1]
        // 只有日期所在年为闰年且已经跨过二月，才补一天。
        if m == 2 && isLeapYear(year) {
            answer++
        }
    }

    return answer + day
}

func isLeapYear(year int) bool {

    return year%400 == 0 || (year%4 == 0 && year%100 != 0)
}

func atoi(s string) int {
    num := 0
    for i := 0; i < len(s); i++ {

        num = num*10 + int(s[i]-'0')
    }

    return num
}

    复杂度分析

    • 时间复杂度：$O(Y+1)$，Y 为与参考年份的差，题目日期范围固定时可视为常数。
    • 空间复杂度：$O(1)$。

    关键点总结

    [!green]

    • 当前年和当前月不能作为完整一段重复加入。
    • 2100 能被一百整除但不能被四百整除，是平年。

    易错点总结

    [!yellow]

    • 只用四年一闰会把2100的二月算多一天。
    • 未考虑两个日期先后，直接返回有符号差可能为负。
    • 一月或二月就无条件补闰日，会给尚未经过二月末的日期多加一天。
