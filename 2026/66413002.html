    题目描述

    ✅ 面试题 16.07. 最大数值

    题意分析

    不使用比较运算符或条件分支，返回两个三十二位有符号整数中的较大值。

    解法：宽差符号位 + 算术选择

    核心思路

    [!blue]
    用安全差值的符号生成零一选择位。 在足够宽的整数中计算 d=a-b，避免原类型溢出改变符号。算术右移到最高位后，结果为零或负一，再与一按位与，得到 k：d 为负时为一，否则为零。

    用 a×(k异或1)+b×k 合成结果。k 为零时保留 a，k 为一时保留 b，两项只有一项非零，因此不会返回第三个值；相等时选择 a 也合法。

    解题步骤

    1. 在足够宽的类型中计算两数之差。
    2. 提取差值符号并转成零一选择位。
    3. 用互补权重选择 a 或 b。
    4. 返回选择结果。

    示例：a=1、b=2 时，差值为负，k=1，返回 b。a 为最小 int、b 为最大 int 时，宽差值仍能正确保留负号，不会被三十二位减法溢出反转。

    代码实现

    class Solution {
    public int maximum(int a, int b) {
        // 先扩宽两个输入再相减，符号掩码与一后得到零一选择位。
        int k = (int) (((long) a - (long) b) >> 63) & 1;

        return a * (k ^ 1) + b * k;
    }
}

    func maximum(a int, b int) int {
    // 先扩宽两个输入再相减，符号掩码与一后得到零一选择位。
    k := int(((int64(a) - int64(b)) >> 63) & 1)
    return a*(k^1) + b*k
}

    复杂度分析

    • 时间复杂度：$O(1)$。
    • 空间复杂度：$O(1)$。

    关键点总结

    [!green]

    • 差值必须先变宽再相减。
    • 右移得到的是符号掩码，与一后才是零一选择位。
    • 选择位一表示应取 b，零表示应取 a。

    易错点总结

    [!yellow]

    • 在窄类型减完后才转换：溢出已经发生。
    • 省略与一的操作：负一不是零一选择位，乘法会得到错误结果。
    • 两项权重接反：得到较小值。
    • 用带比较条件的三目表达式：违反题目对比较操作的限制。
