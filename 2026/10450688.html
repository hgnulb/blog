    题目描述

    ✅ 722. 删除注释

    题意分析

    删除按行输入源码中的行注释和块注释，保留其余字符。删除后的空字符串不输出，普通空格不能擅自删除。

    解法：逐字符状态机

    核心思路

    [!blue]

    inBlock 表示是否位于块注释中。在块内只识别结束标记；块外的行注释丢弃本行剩余内容，块注释开始标记切换状态，其余字符写入缓冲。

    块注释可以跨行，因此状态和输出缓冲都必须跨物理行保留。只有行末已经离开块注释，才算一条完整逻辑行，可以输出并清空缓冲。

    解题步骤

    • 判断双字符标记前确认同一物理行仍有下一字符。
    • 块内只查结束标记，其他字符跳过。
    • 块外识别行注释、块注释开始或普通字符。
    • 行末处于块外且缓冲非空时输出。

    a/*x 与 y*/b//z 删除后拼成一条 ab；不能在第一行后提前输出 a。

    代码实现

    class Solution {
    public List<String> removeComments(String[] source) {
        List<String> ans = new ArrayList<>();
        StringBuilder line = new StringBuilder();
        boolean inBlock = false;

        for (String code : source) {
            for (int i = 0; i < code.length();) {
                // 块内只识别结束标记，双字符检查限定在当前物理行
                if (inBlock) {
                    if (i + 1 < code.length()
                            && code.charAt(i) == '*' && code.charAt(i + 1) == '/') {
                        inBlock = false;
                        i += 2;
                    } else {
                        i++;
                    }
                } else if (i + 1 < code.length()
                        && code.charAt(i) == '/' && code.charAt(i + 1) == '/') {
                    break;
                } else if (i + 1 < code.length()
                        && code.charAt(i) == '/' && code.charAt(i + 1) == '*') {
                    inBlock = true;
                    i += 2;
                } else {
                    line.append(code.charAt(i++));
                }
            }

            // 离开块注释才完成逻辑行，否则保留缓冲继续跨行拼接
            if (!inBlock && line.length() > 0) {
                ans.add(line.toString());
                line.setLength(0);
            }
        }
        return ans;
    }
}

    func removeComments(source []string) []string {
    ans := make([]string, 0)
    line := make([]byte, 0)
    inBlock := false

    for _, code := range source {
        for i := 0; i < len(code); {
            // 块内只识别结束标记，双字符检查限定在当前物理行
            if inBlock {
                if i+1 < len(code) && code[i] == '*' && code[i+1] == '/' {
                    inBlock = false
                    i += 2
                } else {
                    i++
                }
            } else if i+1 < len(code) && code[i] == '/' && code[i+1] == '/' {
                break
            } else if i+1 < len(code) && code[i] == '/' && code[i+1] == '*' {
                inBlock = true
                i += 2
            } else {
                line = append(line, code[i])
                i++
            }
        }

        // 离开块注释才完成逻辑行，否则保留缓冲继续跨行拼接
        if !inBlock && len(line) > 0 {
            ans = append(ans, string(line))
            line = line[:0]
        }
    }
    return ans
}

    复杂度分析

    • 时间复杂度：$O(C)$，C 是输入总字符数。
    • 空间复杂度：不计结果为 $O(L)$，L 是最长删除后逻辑行的长度；计入结果为 $O(C)$。

    关键点总结

    [!green]

    • 当前块状态优先于其他注释标记。
    • 命中双字符标记一次前进两格。
    • 空字符串与只含空格的字符串不同。

    易错点总结

    [!yellow]

    • 每行清空缓冲会断开跨行注释前后的代码。
    • 在块内仍识别行注释，会错过真实结束标记。
    • 把上一行末尾与下一行开头拼成标记，违反同行相邻要求。
