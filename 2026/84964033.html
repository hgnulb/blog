    题目描述

    ✅ 1401. 圆和矩形是否有重叠

    题意分析

    圆与轴对齐矩形只要存在一个公共点就算重叠，相切也算。求矩形内离圆心最近的点即可判断。

    解法：几何最近点

    核心思路

    [!blue]

    横纵坐标各自限制在矩形范围内，最近点由两个方向分别截断得到。圆心在某方向范围内就保持该坐标，否则取近侧端点。

    最近点距离平方不超过半径平方，则该点同时属于圆与矩形；若连最近点都超出半径，矩形其他点也不可能在圆内。

    解题步骤

    • 分别求圆心坐标在横纵区间上的最近值。
    • 计算两方向差的平方和。
    • 与半径平方比较，包含等号。

    圆心(0,0)、半径一，矩形[1,-2,2,2] 的最近点为(1,0)，恰好相切，返回真；四个角都在圆外，只查角点会漏掉。

    代码实现

    class Solution {
    public boolean checkOverlap(
            int radius, int xCenter, int yCenter, int x1, int y1, int x2, int y2) {

        // 轴对齐矩形的横纵范围独立，分别取离圆心最近的坐标。
        int cx = clamp(xCenter, x1, x2);
        int cy = clamp(yCenter, y1, y2);

        int dx = xCenter - cx;
        int dy = yCenter - cy;

        // 最近点位于圆内或边界上时有交集，相切也算。
        return dx * dx + dy * dy <= radius * radius;
    }

    private int clamp(int v, int lo, int hi) {
        if (v < lo) {
            return lo;
        }

        if (v > hi) {
            return hi;
        }

        return v;
    }
}

    func checkOverlap(radius int, xCenter int, yCenter int, x1 int, y1 int, x2 int, y2 int) bool {

    // 轴对齐矩形的横纵范围独立，分别取离圆心最近的坐标。
    cx := clamp(xCenter, x1, x2)
    cy := clamp(yCenter, y1, y2)

    dx := xCenter - cx
    dy := yCenter - cy

    // 最近点位于圆内或边界上时有交集，相切也算。
    return dx*dx+dy*dy <= radius*radius
}

func clamp(v, lo, hi int) int {
    if v < lo {
        return lo
    }
    if v > hi {
        return hi
    }
    return v
}

    复杂度分析

    • 时间复杂度：$O(1)$。
    • 空间复杂度：$O(1)$。

    关键点总结

    [!green]

    • 矩形轴对齐，两个坐标方向才能独立最小化。
    • 最近点可能是内部、边中部或角点。

    易错点总结

    [!yellow]

    • 只检查四角，会漏掉与边中部相切的情况。
    • 只判断圆心在矩形内，会漏掉外部相交。
    • 左边用平方距离、右边只用半径，会比较不同量。
