    题目描述

    ✅ 137. 只出现一次的数字 II

    题意分析

    数组中一个数出现一次，其余每个数出现三次，求单次出现的数。逐个二进制位统计，三次重复的贡献取模后会消失。

    解法一：逐位计数取模

    核心思路

    [!blue]

    对每一位统计数组中一的数量，出现三次的数对该位贡献零或三，取模后全部消失；余下零或一就是唯一数字在该位的值。

    遍历完整的 32 位，包括符号位。Java 直接在 int 中重建补码；Go 先以 uint32 提取和拼接位，再转成 int32 恢复符号，最后转为返回类型。

    解题步骤

    1. 初始化结果为零，依次枚举第零位至第三十一位。
    2. 扫描所有数，取出当前位并累计。
    3. 计数对三取模为一时，将结果对应位置一。
    4. 返回重建出的带符号结果。

    例如 [2,2,3,2] 中，第零位计数为一，第一位计数为四，两者对三取模均为一，因此结果为二进制 11，即 3。

    代码实现

    class Solution {
    public int singleNumber(int[] nums) {
        int result = 0;

        for (int bit = 0; bit < 32; bit++) {
            int count = 0;

            for (int num : nums) {
                count += (num >>> bit) & 1;
            }

            // 三次重复的位贡献被模三消去，剩下的是单次数在本位的值。
            if (count % 3 != 0) {
                result |= 1 << bit;
            }
        }

        return result;
    }
}

    func singleNumber(nums []int) int {
    var result uint32
    for bit := 0; bit < 32; bit++ {
        count := 0
        for _, num := range nums {
            count += int((uint32(num) >> bit) & 1)
        }
        // 三次重复的位贡献被模三消去，剩下的是单次数在本位的值。
        if count%3 != 0 {
            result |= uint32(1) << bit
        }
    }
    // 先恢复三十二位符号，再转换到返回类型。
    return int(int32(result))
}

    复杂度分析

    • 时间复杂度：$O(32n)$，固定扫描 32 个位，每位遍历全部元素。
    • 空间复杂度：$O(1)$，只记录当前位计数与结果。

    关键点总结

    [!green]

    • 三次重复按位贡献均为三的倍数，取模后只剩单次数的位。
    • 必须包含第三十一位，负数同样通过补码还原。
    • Go 的 uint32 → int32 → int 转换负责把符号位还原为负值。

    解法二：双变量位状态机

    核心思路

    [!blue]

    双变量状态机把各位的模三计数并行保存。每个位用 (twos,ones) 编码零次、一次、两次，对应 00、01、10；再读到一次一后回到 00。

    先更新 ones=(ones^num)&~twos，再使用新的 ones 更新 twos=(twos^num)&~ones，阻止两个状态同时置位。最后 ones 保存单次出现数字的全部位，符号位也遵循同一规则。

    解题步骤

    • 初始化 ones = 0、twos = 0，所有位的计数余数均为 0。
    • 依次读入每个 num，先更新 ones，再用更新后的 ones 更新 twos。
    • 遍历结束返回 ones。

    以 [2, 2, 3, 2] 的第 1 位为例，该位依次读到 1、1、1、1，状态依次为 01、10、00、01，最终余数为 1；第 0 位只有数字 3 贡献一次 1，也停在 01，两位合起来得到 3。

    代码实现

    class Solution {
    public int singleNumber(int[] nums) {
        int ones = 0;
        int twos = 0;

        for (int num : nums) {
            // 各位并行维护模三状态，第二行必须读取更新后的 ones。
            ones = (ones ^ num) & ~twos;
            twos = (twos ^ num) & ~ones;
        }

        return ones;
    }
}

    func singleNumber(nums []int) int {
    ones, twos := 0, 0
    for _, num := range nums {
        // 各位并行维护模三状态，第二行必须读取更新后的 ones。
        ones = (ones ^ num) &^ twos
        twos = (twos ^ num) &^ ones
    }
    return ones
}

    复杂度分析

    • 时间复杂度：$O(n)$，每个元素只触发常数次位运算。
    • 空间复杂度：$O(1)$，只使用两个状态变量。

    关键点总结

    [!green]

    • 状态机是“逐位计数后模 3”的并行写法；ones、twos 分别编码余数 1、2。
    • 更新顺序属于公式的一部分：先算 ones，再让 twos 排除新的 ones。
    • 位运算直接作用于补码，符号位与普通位没有区别，因此正负数统一处理。

    易错点总结

    [!yellow]

    • 同时用旧值计算 ones 和 twos：第一次读入某个为 1 的位后，两者都会置 1，产生不存在的 11 状态。
    • 漏掉清除掩码，只写 ones ^= num、twos ^= num：状态不会在第三次出现时归零。
    • 套用 136 题的单纯异或：一个数字异或三次仍等于自身，无法消掉出现三次的元素。
    • 位计数不能漏掉符号位或先取绝对值；Go 直接把无符号结果转成 64 位 int 会把负数变成正数，必须先转 int32。
