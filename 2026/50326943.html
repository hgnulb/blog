    LeetCode 2462. 雇佣 K 位工人的总代价

    2026-07-14 HGNULB 约 4 分钟
    文章信息 3 个分类 · 4 个标签
    分类

    标签

    题目描述

    ✅ 2462. 雇佣 K 位工人的总代价

    题意分析

    每轮只能从当前前c名或后c名候选中雇佣最低费用者，并列时优先较小下标，累计k轮费用。

    解法：两端候选堆与中间补充指针

    核心思路

    [!blue]

    左右两堆分别保存两端候选费用，i、j指向尚未进入任何堆的中间区间。比较两堆最小值后，从选中的那侧补进一个新候选。

    解题步骤

    1. 先填左堆最多c人，再填右堆且不越过i，避免重叠。
    2. 每轮比较堆顶，费用相等时选左堆。
    3. 弹出所选费用计入64位总和。
    4. 中间仍有未入堆者时，从同一侧补一个；共执行k轮。

    代码实现

    class Solution {
    public long totalCost(int[] costs, int k, int candidates) {
        int n = costs.length;
        PriorityQueue<Integer> left = new PriorityQueue<>();
        PriorityQueue<Integer> right = new PriorityQueue<>();
        int i = 0;
        int j = n - 1;

        while (i < candidates) {
            left.offer(costs[i++]);
        }

        // j >= i 防止把 left 已经收走的人重复压进 right，重叠情形靠它兜住。
        while (j >= i && n - 1 - j < candidates) {
            right.offer(costs[j--]);
        }

        // 总和量级 1e10，必须用 long。
        long ans = 0;

        for (int t = 0; t < k; t++) {
            // 相等时取左边，即「代价相同选下标更小者」。
            if (right.isEmpty() || (!left.isEmpty() && left.peek() <= right.peek())) {
                ans += left.poll();

                // 中间地带 [i, j] 还有人才补，补完窗口大小恢复。
                if (i <= j) {
                    left.offer(costs[i++]);
                }
            } else {
                ans += right.poll();

                if (i <= j) {
                    right.offer(costs[j--]);
                }
            }
        }

        return ans;
    }
}

    import (
    "container/heap"
)

func totalCost(costs []int, k int, candidates int) int64 {
    n := len(costs)
    left, right := &IntHeap{}, &IntHeap{}
    i, j := 0, n-1
    for i < candidates {
        heap.Push(left, costs[i])
        i++
    }
    // j >= i 防止把 left 已经收走的人重复压进 right，重叠情形靠它兜住。
    for j >= i && n-1-j < candidates {
        heap.Push(right, costs[j])
        j--
    }
    // 总和量级 1e10，必须用 int64。
    var ans int64
    for t := 0; t < k; t++ {
        // 相等时取左边，即「代价相同选下标更小者」。
        if right.Len() == 0 || (left.Len() > 0 && (*left)[0] <= (*right)[0]) {
            ans += int64(heap.Pop(left).(int))
            // 中间地带 [i, j] 还有人才补，补完窗口大小恢复。
            if i <= j {
                heap.Push(left, costs[i])
                i++
            }
        } else {
            ans += int64(heap.Pop(right).(int))
            if i <= j {
                heap.Push(right, costs[j])
                j--
            }
        }
    }
    return ans
}

type IntHeap []int

func (h IntHeap) Len() int { return len(h) }

func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }

func (h IntHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }

func (h *IntHeap) Push(x any) { *h = append(*h, x.(int)) }

func (h *IntHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

    复杂度分析

    • 时间复杂度：O((c+k) log(c+1))。
    • 空间复杂度：O(min(n,2c))。

    关键点总结

    [!green]

    左右候选的所有原下标分别有序分居两侧，所以跨堆平局选左。堆内相同费用无需保留下标：选走哪一份对剩余费用多重集合及同侧补人规则没有影响，返回值仅要求总费用。

    易错点总结

    [!yellow]

    • 两端填堆区间可能重叠，需要i<=j限制。
    • 从哪一侧弹出，就从同一侧补人。
    • 不允许全局排序后直接取k个最便宜者，会忽略候选范围。
    • 总费用用64位。
