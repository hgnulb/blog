    题目描述

    ✅ 122. 买卖股票的最佳时机 II

    题意分析

    交易次数不限，但不能同时持有多份股票，求最大利润。可以把每段上涨行情都利用起来；单日输入的可得利润为 0。

    解法：贪心累加所有上涨差价

    核心思路

    [!blue]

    一笔交易的利润可以拆成持有期间的相邻日差值。保留所有正差价、跳过非正差价，就能覆盖上涨并避开下跌；把连续上涨合并成一笔交易即可实现这些收益。

    [7, 1, 5, 3, 6, 4] 有两段可获利上涨，利润为 (5 - 1) + (6 - 3) = 7。第 121 题只允许一次交易，不能使用这里的累加规则。

    解题步骤

    • 从第二天开始，计算当天与前一天的价格差。
    • 差价为正时累加到利润中；非正时跳过。
    • 遍历结束后返回累计利润。

    代码实现

    class Solution {
    public int maxProfit(int[] prices) {
        int ans = 0;

        for (int i = 1; i < prices.length; i++) {
            // 连续上涨的整段利润等于这些正相邻差价之和。
            if (prices[i] > prices[i - 1]) {
                ans += prices[i] - prices[i - 1];
            }
        }

        return ans;
    }
}

    func maxProfit(prices []int) int {
    ans := 0
    for i := 1; i < len(prices); i++ {
        // 连续上涨的整段利润等于这些正相邻差价之和。
        if prices[i] > prices[i-1] {
            ans += prices[i] - prices[i-1]
        }
    }
    return ans
}

    复杂度分析

    • 时间复杂度：$O(n)$，只遍历价格数组一次。
    • 空间复杂度：$O(1)$。

    关键点总结

    [!green]

    • 多次交易允许收集每一段上涨，利润等于所有正相邻差价之和。
    • 下跌和持平不会产生收益，直接跳过。
    • 该贪心依赖“交易次数不限且无手续费、冷冻期”等额外限制。

    易错点总结

    [!yellow]

    • 套用第 121 题的单次交易逻辑，会漏掉后续上涨区间。
    • 循环应从下标 1 开始，否则访问前一天会越界。
    • 只累加正差价，不能对差价取绝对值。
    • 单元素或持续下跌数组应返回 0。
