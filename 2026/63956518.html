    题目描述

    ✅ 1074. 元素和为目标值的子矩阵数量

    题意分析

    统计元素和等于目标的非空连续子矩阵。矩阵可以含负数，不能依靠区间和随扩张增加来收缩窗口。

    解法：行压缩 + 前缀和计数

    核心思路

    [!blue]

    固定上下边界，把这几行逐列累加成一维列和。此时每个连续列区间恰好对应一个子矩阵，问题化为一维定和子数组计数。

    下边界每增加一行就增量更新列和；每对行边界重新建立前缀频次表，预置空前缀零一次。当前前缀和减目标的历史次数，就是以当前列结束的矩形数，先查询再登记保证非空。

    解题步骤

    • 每个上边界重新清零列和。
    • 逐步下移下边界，累加新行。
    • 每对边界独立统计一维前缀和频次。
    • 先查互补历史前缀，再登记当前前缀。

    [[0,1,0],[1,1,1],[0,1,0]]、目标零，只有四个角上的单格满足，答案四；[[0,0]] 有三个非空零和区间。

    代码实现

    // 问题转化为一维数组中和为目标值的子数组数量。
class Solution {
    public int numSubmatrixSumTarget(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        int res = 0;

        for (int top = 0; top < m; top++) {
            // 更换上边界后重置，下边界推进时逐行累加
            int[] colSum = new int[n];
            for (int bottom = top; bottom < m; bottom++) {
                for (int c = 0; c < n; c++) {
                    colSum[c] += matrix[bottom][c];
                }

                Map<Integer, Integer> cnt = new HashMap<>();
                // 空前缀负责从第一列开始的合法区间
                cnt.put(0, 1);
                int sum = 0;
                for (int v : colSum) {
                    sum += v;
                    // 先查历史再登记当前前缀，避免统计空区间
                    res += cnt.getOrDefault(sum - target, 0);
                    cnt.put(sum, cnt.getOrDefault(sum, 0) + 1);
                }
            }
        }

        return res;
    }
}

    // 问题转化为一维数组中和为目标值的子数组数量。
func numSubmatrixSumTarget(matrix [][]int, target int) int {
	m, n := len(matrix), len(matrix[0])
	res := 0

	for top := 0; top < m; top++ {
		// 更换上边界后重置，下边界推进时逐行累加
		colSum := make([]int, n)
		for bottom := top; bottom < m; bottom++ {
			for c := 0; c < n; c++ {
				colSum[c] += matrix[bottom][c]
			}

			// 空前缀负责从第一列开始的合法区间
			cnt := map[int]int{0: 1}
			sum := 0
			for _, v := range colSum {
				sum += v
				// 先查历史再登记当前前缀，避免统计空区间
				res += cnt[sum-target]
				cnt[sum]++
			}
		}
	}

	return res
}

    复杂度分析

    • 时间复杂度：期望 $O(m^2n)$，每对行边界做线性列扫描。
    • 空间复杂度：$O(n)$，列和及当前前缀频次表。

    关键点总结

    [!green]

    • 改变行区间后，旧频次不能混入新的一维问题。
    • 同一前缀和的多次出现分别贡献答案。

    易错点总结

    [!yellow]

    • 下边界从零而非上边界开始：[[1],[2]]、目标一会把第一行重复计数。
    • 列和赋值而非累加，会丢失跨行贡献。
    • 当前前缀先入表，在目标零时会把空区间计入。
    • 频次只存是否存在，会漏掉重复前缀产生的不同区间。
