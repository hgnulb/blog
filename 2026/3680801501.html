    补充题 114. 六个数字组成最大合法时间

    2026-09-13 HGNULB 约 4 分钟
    文章信息 3 个分类 · 2 个标签
    分类
    补充题 中等 华为
    标签
    回溯 枚举

    题目描述

    原题：✅ 949. 给定数字能组成的最大时间

    给定六个 0…9 的数字，恰好使用每个位置一次，组成合法的 HH:mm:ss，返回一天中最晚的时间。允许前导零；无法组成时返回空字符串。

    示例 1：

    输入：digits = [2,3,5,9,5,9]
输出："23:59:59"
解释：六个数字组成当天最晚的合法时间。

    示例 2：

    输入：digits = [9,9,9,9,9,9]
输出：""
解释：无法组成合法小时。

    提示：

    • 小时为 00…23，分钟和秒为 00…59。
    • 重复数字也必须按输入次数使用。

    题意分析

    从四位 HH:mm 扩展为六位 HH:mm:ss，采用 24 小时制。

    解法：枚举排列后比较一天内秒数

    核心思路

    [!blue]

    枚举六个位置的所有排列，共不超过 720 种。每个完整排列拆成小时、分钟、秒，检查范围后转为从零点开始的秒数。保留最大秒数，再按两位格式输出。

    解题步骤

    1. 按数字下标枚举六个位置的排列，允许输入值重复。
    2. 完整排列拆出时、分、秒，检查各自上界。
    3. 转换为总秒数取最大，再按两位补零格式输出。

    代码实现

    class Solution {
    public String largestTime(int[] digits) {
        int[] best = {-1};

        dfs(digits, new boolean[6], new int[6], 0, best);

        if (best[0] < 0) {
            return "";
        }

        int value = best[0];

        return String.format(
                Locale.ROOT, "%02d:%02d:%02d", value / 3600, value / 60 % 60, value % 60);
    }

    private void dfs(int[] digits, boolean[] used, int[] path, int depth, int[] best) {
        if (depth == 6) {
            int h = path[0] * 10 + path[1];
            int m = path[2] * 10 + path[3];
            int s = path[4] * 10 + path[5];

            if (h < 24 && m < 60 && s < 60) {
                best[0] = Math.max(best[0], h * 3600 + m * 60 + s);
            }

            return;
        }

        for (int i = 0; i < 6; i++) {
            if (!used[i]) {
                used[i] = true;
                path[depth] = digits[i];
                dfs(digits, used, path, depth + 1, best);
                used[i] = false;
            }
        }
    }
}

    import "fmt"

func largestTime(digits []int) string {
    best := -1
    used := [6]bool{}
    path := [6]int{}
    var dfs func(int)
    dfs = func(depth int) {
        if depth == 6 {
            h, m, s := path[0]*10+path[1], path[2]*10+path[3], path[4]*10+path[5]
            if h < 24 && m < 60 && s < 60 {
                best = max(best, h*3600+m*60+s)
            }
            return
        }
        for i := 0; i < 6; i++ {
            if !used[i] {
                used[i] = true
                path[depth] = digits[i]
                dfs(depth + 1)
                used[i] = false
            }
        }
    }
    dfs(0)
    if best < 0 {
        return ""
    }
    return fmt.Sprintf("%02d:%02d:%02d", best/3600, best/60%60, best%60)
}

    复杂度分析

    • 时间复杂度：六位固定输入，最多枚举 6!=720 个排列，有固定上界。
    • 空间复杂度：六位固定输入，辅助空间有固定上界。

    关键点总结

    [!green]

    六个位置最多 720 种排列，直接枚举足够；按下标标记使用情况，不能用数字值集合去重资源。

    易错点总结

    [!yellow]

    必须检查分钟和秒的上界；00:00:00 是合法结果，不能把秒数 0 当作无解。
