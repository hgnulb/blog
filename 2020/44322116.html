    题目描述

    ✅ 956. 最高的广告牌

    题意分析

    将钢筋分给两根支架或不使用，使两根支架等高，求能够得到的最大高度。

    解法：高度差动态规划

    核心思路

    [!blue]
    按两侧高度差保存较矮侧的最大高度。 同样差值的两种安排，较矮侧更高的那一种始终更有利：后续放置产生的差值变化相同，但它能得到更高的最终支架。因此每个差值只保留这一种最优高度。

    当前差值为 d、较矮高度为 h，加入钢筋 x 有三种选择：不用保持原状态；放高侧得到差值 d+x、高度 h；放矮侧得到差值 d-x 、新矮侧高度 h+min(d,x)。最后差值零的最大高度就是答案。

    每根钢筋使用旧状态表生成新表，先复制旧表表示不使用。可达且高度为零的状态也必须写入映射，不能与不存在的键混为一谈，否则后续无法继续转移。

    解题步骤

    1. 初始化差值零、矮侧高度零的可达状态。
    2. 每根钢筋先复制旧表，保留不使用的选择。
    3. 枚举旧状态，计算放高侧与放矮侧的结果并取最大值。
    4. 完成后返回差值零的高度。

    示例：[1,1] 中，第一根产生可达的差值一、高度零，第二根才能配成高度一。[1,2,3,7] 可以不用七，将一、二与三分到两侧，最大高度为三。

    代码实现

    class Solution {
    public int tallestBillboard(int[] rods) {
        // dp[diff] = 高度差为 diff 时，较矮一侧能达到的最大高度。
        Map<Integer, Integer> dp = new HashMap<>();
        dp.put(0, 0);

        for (int x : rods) {
            // 复制一份即「这根不用」的转移，同时避免同一根被重复使用。
            Map<Integer, Integer> next = new HashMap<>(dp);
            for (Map.Entry<Integer, Integer> e : dp.entrySet()) {
                int diff = e.getKey();
                int best = e.getValue();

                // 放到较高的一侧：矮侧不变，差值变大。
                int d1 = diff + x;
                next.put(d1, Math.max(next.getOrDefault(d1, -1), best));

                // 放到较矮的一侧：可能反超，新矮侧高度为 best + min(diff, x)。
                int d2 = Math.abs(diff - x);
                int b2 = best + Math.min(diff, x);
                next.put(d2, Math.max(next.getOrDefault(d2, -1), b2));
            }
            dp = next;
        }
        return dp.getOrDefault(0, 0);
    }
}

    func tallestBillboard(rods []int) int {
    // dp[diff] = 高度差为 diff 时，较矮一侧能达到的最大高度。
    dp := map[int]int{0: 0}

    for _, x := range rods {
        // 复制一份即「这根不用」的转移，同时避免同一根被重复使用。
        next := make(map[int]int, len(dp)*2+1)
        for k, v := range dp {
            next[k] = v
        }

        for diff, best := range dp {
            // 放到较高的一侧：矮侧不变，差值变大。
            d1 := diff + x
            // 缺键表示状态不存在，不能与可达的零高度混为一谈。
            if old, ok := next[d1]; !ok || old < best {
                next[d1] = best
            }

            // 放到较矮的一侧：可能反超，新矮侧高度为 best + min(diff, x)。
            d2 := abs(diff - x)
            b2 := best + min(diff, x)
            if old, ok := next[d2]; !ok || old < b2 {
                next[d2] = b2
            }
        }
        dp = next
    }
    return dp[0]
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}

    复杂度分析

    • 时间复杂度：期望 $O(nS)$，S 为钢筋总长度，差值状态不超过 S+1。
    • 空间复杂度：$O(S)$，前后两张状态表。

    关键点总结

    [!green]

    • 高度为零仍可能是重要的可达状态。
    • 相同差值只保留较高的矮侧，利用支配关系压缩状态。
    • 新旧表分开，保证一根钢筋只处理一次。

    易错点总结

    [!yellow]

    • 缺失键默认零，与新值零比较后不写入：可达状态丢失，后续无法配平。
    • 遍历时修改同一状态表：新状态可能再次使用本根钢筋。
    • 放矮侧始终增加 x：反超后新矮侧应是原高侧。
    • 返回全部状态中的最高值：两侧可能仍不等高。
