    this 关键字的应用

    [!blue]

    1. 使用 this 关键字引用当前类的实例变量
    2. 使用 this 关键字调用当前类的实例方法
    3. 在构造方法中使用 this 关键字作为参数
    4. 使用 this 关键字作为方法调用中的参数传递
    5. 使用 this() 关键字调用当前类的其它构造方法（必须放在构造方法的第一行）
    6. 使用 this 关键字返回当前类的实例

    使用 this 关键字引用当前类的实例变量

    this 指向当前对象自身。当构造方法或 setter 的参数名与实例变量同名时，参数会遮蔽实例变量，直接写变量名访问到的是参数。此时用 this.变量名 明确指向当前对象的实例变量，这是 this 最常见的用法。

    class Test {
    int a;
    int b;

    Test(int a, int b) {
        this.a = a;
        this.b = b;
    }

    void display() {
        System.out.println("a = " + a + " b = " + b);
    }

    public static void main(String[] args) {
        Test object = new Test(10, 20);
        object.display();
    }
}

    [!green-fold] 运行结果
    a = 10 b = 20

    构造方法中 this.a = a 把参数 a 的值赋给了实例变量 a。如果漏写 this，就变成参数自己赋值给自己，实例变量将保持默认值 0——这是面试和实际编码中的经典坑。

    使用 this 关键字调用当前类的实例方法

    在实例方法内部调用本类的其他实例方法时，可以写 this.方法名()。这里的 this 通常可以省略，编译器会自动补上，显式写出主要是为了可读性。

    class Test {
    void display() {
        this.show();
        System.out.println("Inside display function");
    }

    void show() {
        System.out.println("Inside show function");
    }

    public static void main(String[] args) {
        Test t1 = new Test();
        t1.display();
    }
}

    [!green-fold] 运行结果
    Inside show function

    Inside display function

    display() 第一行的 this.show() 先执行完，才轮到它自己的打印语句，效果与直接写 show() 完全相同。

    在构造方法中使用 this 关键字作为参数

    this 代表当前正在构造或运行的对象，因此可以把它作为参数传给别的类，让对方持有当前对象的引用。这是事件回调、对象之间建立关联的常见写法。

    class A {
    B obj;

    A(B obj) {
        this.obj = obj;
        obj.display();
    }
}

class B {
    int x = 5;

    B() {
        A obj = new A(this);
    }

    void display() {
        System.out.println("Value of x in Class B: " + x);
    }

    public static void main(String[] args) {
        B obj = new B();
    }
}

    [!green-fold] 运行结果
    Value of x in Class B: 5

    B 的构造方法把自身引用 this 传给 A，A 通过这个引用回调 obj.display()，访问到的正是这个 B 对象的 x。

    使用 this 关键字作为方法调用中的参数传递

    与上一节类似，在实例方法中也可以把 this 作为实参传给其他方法，常用于把「自己」交给别的方法处理。

    class Test {
    int a;
    int b;

    Test() {
        a = 10;
        b = 20;
    }

    void display(Test obj) {
        System.out.println("a = " + obj.a + " b = " + obj.b);
    }

    void get() {
        display(this);
    }

    public static void main(String[] args) {
        Test object = new Test();
        object.get();
    }
}

    [!green-fold] 运行结果
    a = 10 b = 20

    get() 中的 this 就是 main 里创建的 object，display(this) 因此打印出该对象的 a 和 b。

    使用 this() 关键字调用当前类的其它构造方法（必须放在构造方法的第一行）

    当多个构造方法存在重复的初始化逻辑时，可以用 this(参数列表) 让一个构造方法复用另一个，避免代码重复。注意 this() 只能出现在构造方法中，且必须是第一条语句。

    class Test {
    int a;
    int b;

    Test() {
        this(10, 20);
        System.out.println("Inside default constructor");
    }

    Test(int a, int b) {
        this.a = a;
        this.b = b;
        System.out.println("Inside parameterized constructor");
    }

    public static void main(String[] args) {
        Test object = new Test();
    }
}

    [!green-fold] 运行结果
    Inside parameterized constructor

    Inside default constructor

    无参构造方法第一行的 this(10, 20) 会先把有参构造方法完整执行一遍，再回来执行自己剩下的语句，所以 parameterized 那一行先输出。

    使用 this 关键字返回当前类的实例

    实例方法返回 this，调用方拿到的就是当前对象本身，可以继续调用它的其他方法。这正是链式调用（如 StringBuilder 的 append）的实现原理：每个方法做完自己的事后 return this;，下一个方法调用仍然作用在同一个对象上。

    class Test {
    int a;
    int b;

    Test() {
        a = 10;
        b = 20;
    }

    Test get() {
        return this;
    }

    void display() {
        System.out.println("a = " + a + " b = " + b);
    }

    public static void main(String[] args) {
        Test object = new Test();
        object.get().display();
    }
}

    [!green-fold] 运行结果
    a = 10 b = 20

    get() 返回的就是 object 自身，所以 object.get().display() 等价于 object.display()。

    this 面试考点

    • 静态上下文不可用：this 依赖当前对象，static 方法和 static 代码块属于类而不属于任何对象，没有「当前对象」可指，其中使用 this 直接编译报错，main 方法也不例外。
    • this() 的三条限制：只能出现在构造方法中；必须是第一条语句（因此与 super() 二选一，且最多出现一次）；构造方法之间不能通过 this() 形成循环调用，否则编译器报 recursive constructor invocation 错误。
    • 链式调用原理：方法末尾 return this; 把当前对象交还给调用方，于是 obj.a().b().c() 每一步都作用在同一个对象上，StringBuilder 的 append 就是这样实现的。
    • this 是只读引用：不能对它赋值，this = xxx 无法通过编译。
    • 参数遮蔽：构造方法或 setter 中漏写 this（写成 a = a）是参数给自己赋值，实例变量保持默认值，编译不报错但逻辑出错。

    this 关键字注意事项

    [!amber]

    • this 依赖当前对象，不能在 static 方法和 static 代码块中使用——静态上下文属于类而不属于任何对象，没有「当前对象」可指，编译直接报错，main 方法也不例外。
    • this() 只能出现在构造方法中，且必须是第一条语句；因此在同一个构造方法里，this() 与 super() 只能二选一，且最多出现一次。
    • 构造方法之间不能通过 this() 形成循环调用（例如两个构造方法互相用 this() 调用对方），编译器会报 recursive constructor invocation 错误。
    • this 是一个只读引用，不能对它赋值，this = xxx 无法通过编译。
