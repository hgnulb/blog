    super 关键字的应用

    [!blue]

    • 当子类与父类有同名的实例属性时，可以使用 super 关键字显式调用父类中声明的实例属性。
    • 当子类重写父类的方法时，可以使用 super 关键字调用父类同名的实例方法。
    • 子类构造方法隐含调用 super()。

    当子类与父类有同名的实例属性时，可以使用 super 关键字显式调用父类中声明的实例属性

    属性没有「重写」一说：子类与父类的同名属性会同时存在于子类对象中，子类属性只是遮蔽了父类属性。在子类内部直接写变量名访问的是子类自己的属性，想拿到被遮蔽的父类属性，就要用 super.属性名。典型使用时机：子类定义了与父类同名的字段，又需要读取父类那一份的值。

    class Vehicle {
    int maxSpeed = 120;
}

class Car extends Vehicle {
    int maxSpeed = 180;

    void display() {
        System.out.println("Maximum Speed: " + maxSpeed);
        System.out.println("Maximum Speed: " + super.maxSpeed);
    }
}

class Test {
    public static void main(String[] args) {
        Car car = new Car();
        car.display();
    }
}

    [!green-fold] 运行结果
    Maximum Speed: 180

    Maximum Speed: 120

    Car 对象中同时保存着两份 maxSpeed：直接访问 maxSpeed 得到子类的 180，super.maxSpeed 取到父类的 120。属性访问在编译期按类型静态绑定，不存在方法那样的动态绑定。

    当子类重写父类的方法时，可以使用 super 关键字调用父类同名的实例方法

    子类重写父类方法后，通过对象调用的永远是子类版本（动态绑定），但父类版本并没有丢失，在子类内部用 super.方法名() 就能调到它。典型使用时机：重写时先复用父类逻辑再做扩展，即先 super.method() 再补充自己的处理。

    class Person {
    void message() {
        System.out.println("This is person class");
    }
}

class Student extends Person {
    void message() {
        System.out.println("This is student class");
    }

    void display() {
        message();
        super.message();
    }
}

class Test {
    public static void main(String[] args) {
        Student s = new Student();
        s.display();
    }
}

    [!green-fold] 运行结果
    This is student class

    This is person class

    message() 走动态绑定，调用的是子类重写后的版本；super.message() 则绕过重写，直接执行父类版本，所以两行输出一新一旧。

    子类构造方法隐含调用 super()

    子类对象的实例化必须先完成父类部分的初始化，因此每个子类构造方法的第一行都会调用父类构造方法——要么显式写 super(...)，要么由编译器自动插入 super()。

    class Person {
    Person() {
        System.out.println("Person class Constructor");
    }
}

class Student extends Person {
    Student() {
        super();
        System.out.println("Student class Constructor");
    }
}

class Test {
    public static void main(String[] args) {
        Student s = new Student();
    }
}

    [!green-fold] 运行结果
    Person class Constructor

    Student class Constructor

    父类构造方法先执行完毕，子类构造方法才继续执行，印证了「先父后子」的初始化顺序。

    即使不显式写出 super()，编译器也会自动在子类构造方法的第一行插入对它的调用，因此下面这段代码的运行结果与上面完全相同：

    class Person {
    Person() {
        System.out.println("Person class Constructor");
    }
}

class Student extends Person {
    Student() {
        System.out.println("Student class Constructor");
    }
}

class Test {
    public static void main(String[] args) {
        Student s = new Student();
    }
}

    [!green-fold] 运行结果
    Person class Constructor

    Student class Constructor

    编译器插入的隐式 super() 与显式写出的效果完全一致，输出顺序不变。

    super 面试考点

    • 属性静态绑定 vs 方法动态绑定：同名属性是遮蔽关系，按引用的编译期类型取值；同名方法是重写关系，按对象的运行期类型分派。Vehicle v = new Car(); 时 v.maxSpeed 取父类的值，而 v.display() 执行子类版本。
    • 构造链先父后子：new 一个子类对象时，构造调用沿继承链一路向上追溯到 Object，再从最顶层开始依次执行完毕，保证子类构造体执行时父类部分已初始化完成。
    • super() / this() 必须在第一行且二选一：二者都要求是构造方法的第一条语句，因此不能同时出现，且各自最多出现一次。这条规则保证构造链上父类构造方法恰好执行一次。
    • 父类没有无参构造方法时：子类构造方法必须在第一行显式写 super(参数)，否则编译器插入的默认 super() 找不到目标，直接编译报错。
    • 静态上下文不可用：super 依赖当前对象，static 方法和 static 代码块中没有当前对象，不能使用 super（this 同理）。
    • super 调用只对当前这一次调用生效：super.method() 绕过的只是这一次分派，父类方法内部再调用的普通方法依然走多态（见下面最后一道代码题）。

    this 和 super 常考面试题

    以下关于 super 和 this 关键字的说法中，正确的是（ ）

    [!blue]

    • A. super() 与 this() 可以同时存在于同一个构造方法中
    • B. super() 与 this() 不能同时存在于同一个构造方法中
    • C. super 关键字可以调用父类的成员方法
    • D. super 关键字可以调用父类的构造方法

    [!green-fold] 参考答案
    BCD

    解析：super() 与 this() 都要求位于构造方法的第一行，只能二选一，不能同时出现，所以 A 错、B 对；super.方法名() 可以调用父类成员方法，super(参数) 可以调用父类构造方法，C、D 正确。

    以下关于 super 和 this 关键字的说法中，正确的是（ ）

    [!blue]

    • A. super 关键字可以调用父类的构造方法
    • B. super 关键字可以调用父类的普通方法
    • C. super 与 this 不能同时存在于同一个构造方法中
    • D. super 与 this 可以同时存在于同一个构造方法中

    [!green-fold] 参考答案
    ABD

    解析：A、B 显然正确。C、D 说的是 super 与 this 这两个「关键字」，而不是 super() 与 this() 构造方法调用——作为关键字，二者完全可以出现在同一个构造方法中（例如 this.x = super.x;），所以 D 对、C 错。不能共存的只是 super() 和 this() 这两种构造方法调用，因为它们都必须位于第一行。审题时务必区分「关键字」与「构造方法调用」。

    以下关于 super 和 this 关键字的说法中，错误的是（ ）

    [!blue]

    • A. 在子类构造方法中使用 super() 显式调用父类的构造方法，super() 必须写在子类构造方法的第一行，否则编译不通过
    • B. super() 和 this() 不一定要放在构造方法内第一行
    • C. this() 和 super() 可以同时出现在一个构造函数中
    • D. this() 和 super() 可以在 static 环境中使用，包括 static 方法和 static 语句块

    [!green-fold] 参考答案
    BCD

    解析：A 是正确说法，显式的 super() 必须写在第一行。B 错：super() 和 this() 都必须放在构造方法第一行；C 错：正因为都要求第一行，二者只能二选一；D 错：this 和 super 都依赖当前对象，static 环境中没有当前对象，无法使用。

    以下关于 super 和 this 关键字的说法中，错误的是（ ）

    [!blue]

    • A. this 和 super 关键字都可以访问成员属性，成员方法和构造方法
    • B. 在 main 方法中可以存在 this 或 super 关键字，但不能同时存在
    • C. 在一个类的构造方法中可以同时使用 this 和 super 来调用其他构造方法
    • D. this 关键字指向当前对象自身，super 关键字指向当前对象的直接父类

    [!green-fold] 参考答案
    BC

    解析：B 错：main 是静态方法，没有当前对象，this 和 super 都不能出现，「可以存在其一」的说法不成立；C 错：this() 与 super() 都必须是构造方法的第一条语句，不能同时使用。A、D 是正确说法：this 和 super 都能访问成员属性、成员方法和构造方法（this()/super()）。

    以下代码的输出结果是什么？

    class Base {
    public void methodOne() {
        System.out.print("A");
        methodTwo();
    }

    public void methodTwo() {
        System.out.print("B");
    }
}

class Derived extends Base {
    public void methodOne() {
        super.methodOne();
        System.out.print("C");
    }

    public void methodTwo() {
        super.methodTwo();
        System.out.print("D");
    }
}

public class Test {
    public static void main(String[] args) {
        Base b = new Derived();
        b.methodOne();
    }
}

    [!green-fold] 参考答案
    ABDC

    解析：b.methodOne() 动态绑定到 Derived.methodOne()，其中 super.methodOne() 先输出 A；接着 Base.methodOne() 内部调用 methodTwo()——注意此处仍走动态绑定，实际执行的是 Derived.methodTwo()，它先通过 super.methodTwo() 输出 B，再输出 D；最后回到 Derived.methodOne() 输出 C。考点：super 调用只对「当前这一次调用」生效，父类方法内部的普通方法调用依然是多态的。

    this 和 super 注意事项

    [!amber]

    • 由于 this 和 super 都是在实例化阶段调用，所以不能在静态方法和静态代码块中使用 this 和 super 关键字。
    • 实例成员之间可以通过 this 互相引用：实例方法里可以用 this 访问实例变量、调用其他实例方法；构造方法里还可以用 this() 调用本类的其他构造方法。
    • this() 和 super() 都必须位于构造方法的第一行。因此在同一个构造方法中，二者只能二选一，且最多出现一次。这条规则保证了构造链上父类构造方法恰好执行一次，对象初始化顺序始终是「先父类后子类」。
    • 如果一个类没有显式声明任何构造方法，编译器会自动生成一个无参构造方法，它是 super() 的一条默认调用通路，构造方法的参数列表决定了调用通路的选择。
      • 如果子类指定调用父类的某个构造方法，super 就会不断往上溯源；如果没有指定，则默认调用 super()。
      • 如果父类没有提供无参构造方法，而子类构造方法中又没有显式调用父类的有参构造方法，就会出现编译错误。
      • 也就是说，如果父类只提供了有参构造方法，那么子类必须在构造方法的第一行使用 super(参数) 显式调用它。

    下面的例子中，Person 只有有参构造方法，Student 必须在第一行显式写 super(25)，否则编译器插入的默认 super() 找不到对应的无参构造方法，直接编译报错：

    class Person {
    Person(int age) {
        System.out.println("Person class Constructor " + age);
    }
}

class Student extends Person {
    Student() {
        super(25);
        System.out.println("Student class Constructor");
    }
}

class Test {
    public static void main(String[] args) {
        Student s = new Student();
    }
}

    [!green-fold] 运行结果
    Person class Constructor 25

    Student class Constructor

    子类通过 super(25) 精确指定了父类的有参构造方法，构造顺序依旧先父后子。
