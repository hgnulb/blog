    题目描述

    ✅ 177. 第N高的薪水

    题意分析

    实现函数返回第 N 高的不同薪水值，重复薪水只占一个名次，不足 N 个不同值时返回 NULL。

    解法：去重排序 + 偏移查询

    核心思路

    [!blue]
    去重、降序，再按偏移量取一个值。 第 N 高对应从零开始的偏移 N-1。函数先转换参数，再使用 DISTINCT salary、ORDER BY salary DESC 和 LIMIT N,1 定位。

    查询作为标量表达式返回，最多一行；没有对应行时结果为 NULL，自然覆盖表为空或名次数量不足。

    解题步骤

    1. 将 N 减一，转为偏移量。
    2. 去重薪水并降序排列。
    3. 跳过指定行数，只取一个值。
    4. 通过标量子查询返回结果。

    示例：薪水为 [100,200,300,200]，去重降序为 [300,200,100]。N=3 返回 100，N=4 没有对应值，返回 NULL。

    代码实现

    CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
BEGIN
    -- 序号从 1 起、偏移量从 0 起，先把两者对齐。
    SET N = N - 1;
    RETURN (
        -- DISTINCT 压平并列；N 已转换为从 0 开始的偏移量。
        SELECT DISTINCT salary
        FROM Employee
        ORDER BY salary DESC
        LIMIT N, 1
    );
END

    复杂度分析

    • 时间复杂度：取决于执行计划；无有序访问路径时，扫描、去重和排序通常按 $O(n\log(n+1))$ 估算。
    • 空间复杂度：排序与去重的中间空间通常按 $O(n)$ 上界估算，具体取决于执行计划。

    关键点总结

    [!green]

    • 排名对象是不同薪水值，不是员工行。
    • 序号从一开始，偏移从零开始。
    • 标量空查询返回 NULL，无需替换成其他值。

    易错点总结

    [!yellow]

    • 省略去重：并列薪水占用多个位置。
    • N 不减一：取到下一名。
    • 漏掉降序：取成第 N 低。
    • 无解用零兜底：题目要求返回 NULL。
