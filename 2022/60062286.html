    题目描述

    ✅ 688. 骑士在棋盘上的概率

    题意分析

    骑士每步等概率选择八个方向，出界后不再返回。求恰好走 k 步后仍在棋盘内的概率。

    解法：动态规划状态转移

    核心思路

    [!blue]

    状态记录走完当前步、全程未出界且落在某格的概率。不同历史只要落点相同，后续选择相同，可以把概率合并。

    每个合法下一格接收当前概率的八分之一，出界部分直接丢弃，不能重新分配给合法方向。新一层只读取旧层，最后汇总全部落点。

    解题步骤

    • 起点概率一，其余零。
    • 每一步新建全零下一层。
    • 将当前格概率按固定八分之一分给合法方向。
    • 完成 k 轮后求所有格子的概率和。

    三乘三棋盘从左上走两步，四条存活路径共占 4/64=0.0625；零步时概率为一。 同一起点一步后的存活概率为四分之一。

    代码实现

    // step=0 时起点概率为 1，其余为 0。
class Solution {
    private static final int[][] DIRS = {
        {1, 2},
        {2, 1},
        {-1, 2},
        {-2, 1},
        {1, -2},
        {2, -1},
        {-1, -2},
        {-2, -1},
    };

    public double knightProbability(int n, int k, int row, int column) {
        double[][] dp = new double[n][n];

        dp[row][column] = 1.0;

        for (int step = 1; step <= k; step++) {
            // 下一步只读取旧层，不能原地混合不同步数
            double[][] next = new double[n][n];

            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (dp[i][j] == 0) {
                        continue;
                    }

                    for (int[] d : DIRS) {
                        int ni = i + d[0];
                        int nj = j + d[1];

                        if (ni >= 0 && ni < n && nj >= 0 && nj < n) {
                            // 出界方向也占八分之一，不能按合法方向重新均分
                            next[ni][nj] += dp[i][j] / 8.0;
                        }
                    }
                }
            }

            dp = next;
        }

        // 汇总全部存活落点，不只统计回到起点的概率
        double total = 0.0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                total += dp[i][j];
            }
        }

        return total;
    }
}

    // step=0 时起点概率为 1，其余为 0。
func knightProbability(n int, k int, row int, column int) float64 {
    dirs := make([][2]int, 0, 8)
    dirs = append(dirs, [2]int{1, 2}, [2]int{2, 1}, [2]int{-1, 2}, [2]int{-2, 1})
    dirs = append(dirs, [2]int{1, -2}, [2]int{2, -1}, [2]int{-1, -2}, [2]int{-2, -1})
    dp := make([][]float64, n)
    for i := 0; i < n; i++ {
        dp[i] = make([]float64, n)
    }
    dp[row][column] = 1.0

    for step := 1; step <= k; step++ {
        // 下一步只读取旧层，不能原地混合不同步数
        next := make([][]float64, n)
        for i := 0; i < n; i++ {
            next[i] = make([]float64, n)
        }

        for i := 0; i < n; i++ {
            for j := 0; j < n; j++ {
                if dp[i][j] == 0 {
                    continue
                }
                for _, d := range dirs {
                    ni := i + d[0]
                    nj := j + d[1]
                    if ni >= 0 && ni < n && nj >= 0 && nj < n {
                        // 出界方向也占八分之一，不能按合法方向重新均分
                        next[ni][nj] += dp[i][j] / 8.0
                    }
                }
            }
        }
        dp = next
    }

    // 汇总全部存活落点，不只统计回到起点的概率
    total := 0.0
    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            total += dp[i][j]
        }
    }

    return total
}

    复杂度分析

    • 时间复杂度：$O((k+1)n^2)$，包含初始化与最终求和。
    • 空间复杂度：$O(n^2)$，保留两层概率矩阵。

    关键点总结

    [!green]

    • 合法方向不足八个时，缺失的概率确实流向棋盘外。
    • 问题只要求还在棋盘，不要求回到起点。

    易错点总结

    [!yellow]

    • 除以合法方向数，会错误保留本应流失的概率。
    • 在原层边读边写，会把同一步更新再次扩散。
    • 最终只读起点概率，会漏掉其他存活落点。
