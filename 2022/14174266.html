    题目描述

    ✅ 1096. 花括号展开 II

    题意分析

    表达式中的逗号表示并集，相邻片段表示拼接，花括号可以嵌套。展开所有可能字符串，去重后按字典序返回。

    解法：递归解析表达式

    核心思路

    [!blue]
    按优先级分三层递归解析。 expr 处理逗号并集，term 处理相邻拼接，factor 处理字母串或一对花括号。拼接由 term 内部完成，因此优先于外层的并集。

    每个函数返回当前片段能产生的字符串集合。并集直接合并集合；拼接枚举两集合的笛卡尔积，将每对字符串相连。拼接初值必须为只含空串的集合 {""}，不是空集合。

    所有层共享游标。term 遇到逗号或右括号停止但不消耗它；expr 消耗逗号；factor 消耗左右括号。这个职责划分使嵌套解析后能够从正确位置继续。

    解题步骤

    1. 从 expr 入口解析整个表达式。
    2. expr 先解析一个 term，遇逗号就解析下一项并取并集。
    3. term 反复解析 factor，将集合做笛卡尔积拼接。
    4. factor 遇左括号递归解析内部表达式，再跳过右括号；否则读取字母串。
    5. 最终集合转换为列表，只在最外层排序。

    示例：{a,b}{c,{d,e}} 的左组为 {a,b}，右组为 {c,d,e}。两组拼接后得到 ac、ad、ae、bc、bd、be，按字典序返回。 {a,a}b 的重复分支都生成 ab，集合去重后只返回一个 ab。

    代码实现

    class Solution {
    public List<String> braceExpansionII(String expression) {
        int[] idx = new int[1];
        Set<String> res = parseExpr(expression, idx);
        List<String> list = new ArrayList<>(res);
        Collections.sort(list);
        return list;
    }

    // expr = term (',' term)*，逗号表示并集。
    private Set<String> parseExpr(String s, int[] idx) {
        Set<String> res = parseTerm(s, idx);
        while (idx[0] < s.length() && s.charAt(idx[0]) == ',') {
            idx[0]++;
            res.addAll(parseTerm(s, idx));
        }
        return res;
    }

    // term = factor+，相邻表示笛卡尔积拼接，初值取单位元 {""}。
    private Set<String> parseTerm(String s, int[] idx) {
        Set<String> res = new HashSet<>();
        // 空字符串是拼接的单位元，空集合会让所有结果消失。
        res.add("");
        while (idx[0] < s.length() && s.charAt(idx[0]) != '}' && s.charAt(idx[0]) != ',') {
            Set<String> next = parseFactor(s, idx);
            // 用新集合接收拼接结果，避免一边遍历一边修改原集合。
            Set<String> merged = new HashSet<>();
            for (String a : res) {
                for (String b : next) {
                    merged.add(a + b);
                }
            }
            res = merged;
        }
        return res;
    }

    // factor 可能是单词或 {expr}。
    private Set<String> parseFactor(String s, int[] idx) {
        Set<String> res = new HashSet<>();
        if (s.charAt(idx[0]) == '{') {
            idx[0]++;
            // 左花括号已消耗，递归解析后还要跳过对应右花括号。
            res = parseExpr(s, idx);
            idx[0]++;
            return res;
        }

        StringBuilder sb = new StringBuilder();
        while (idx[0] < s.length()) {
            char c = s.charAt(idx[0]);
            if (c == '{' || c == '}' || c == ',') {
                break;
            }
            sb.append(c);
            idx[0]++;
        }
        res.add(sb.toString());
        return res;
    }
}

    import "sort"

func braceExpansionII(expression string) []string {
	idx := 0
	res := parseExpr(expression, &idx)
	list := make([]string, 0, len(res))
	for k := range res {
		list = append(list, k)
	}
	sort.Strings(list)
	return list
}

// expr = term (',' term)*，逗号表示并集。
func parseExpr(s string, idx *int) map[string]struct{} {
	res := parseTerm(s, idx)
	for *idx < len(s) && s[*idx] == ',' {
		*idx = *idx + 1
		term := parseTerm(s, idx)
		for k := range term {
			res[k] = struct{}{}
		}
	}
	return res
}

// term = factor+，相邻表示笛卡尔积拼接，初值取单位元 {""}。
func parseTerm(s string, idx *int) map[string]struct{} {
	// 空字符串是拼接的单位元，空集合会让所有结果消失。
	res := map[string]struct{}{"": {}}
	for *idx < len(s) && s[*idx] != '}' && s[*idx] != ',' {
		next := parseFactor(s, idx)
		// 用新集合接收拼接结果，避免一边遍历一边修改原集合。
		merged := make(map[string]struct{})
		for a := range res {
			for b := range next {
				merged[a+b] = struct{}{}
			}
		}
		res = merged
	}
	return res
}

// factor 可能是单词或 {expr}。
func parseFactor(s string, idx *int) map[string]struct{} {
	res := make(map[string]struct{})
	if s[*idx] == '{' {
		*idx = *idx + 1
		// 左花括号已消耗，递归解析后还要跳过对应右花括号。
		res = parseExpr(s, idx)
		*idx = *idx + 1
		return res
	}

	start := *idx
	for *idx < len(s) {
		c := s[*idx]
		if c == '{' || c == '}' || c == ',' {
			break
		}
		*idx = *idx + 1
	}
	res[s[start:*idx]] = struct{}{}
	return res
}

    复杂度分析

    • 时间复杂度：设输入长度为 n，累计拼接候选数为 P，最大字符串长度为 L，最终结果数为 K。期望时间为 $O(n+PL+KL\log K)$，分别对应解析、拼接去重和最终排序；结果规模可能随 n 指数增长。
    • 空间复杂度：$O(n+UL)$，U 为同时保留的中间和最终字符串数量，递归栈最坏为 $O(n)$。

    关键点总结

    [!green]

    • 并集与拼接分层，不要用同一套合并操作。
    • 集合负责去重，最终排序负责顺序。
    • 游标由谁消耗必须明确，尤其是逗号和右括号。

    易错点总结

    [!yellow]

    • 拼接从空集合开始：与任何集合做笛卡尔积仍为空，所有答案都会丢失。
    • term 不在逗号处停止：factor 无法消费逗号，可能原地循环。
    • factor 忘记跳过右括号：{a}b 会提前停止，漏掉后面的 b。
    • 省略去重或最终排序：分别会产生重复项或不满足字典序的输出。
