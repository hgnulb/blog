    题目描述

    ✅ 1080. 根到叶路径上的不足节点

    题意分析

    若经过某个节点的所有根到叶路径都小于 limit，这个节点就应删除。只要还有一条原始根到叶路径达到阈值，节点就要保留。

    解法：DFS 剪枝

    核心思路

    [!blue]
    后序递归返回剪枝后的子树根。 dfs(node,need) 中 need 表示从当前节点开始还需达到的路径和，等于 limit 减去祖先贡献。返回空表示当前子树应全部删除。

    先识别原始叶子，只有 node.val<need 时删除，等于阈值则保留。内部节点分别递归处理孩子，将返回值接回；若两侧都被删空，说明没有原始达标路径经过当前节点，它也必须删除。

    节点值可以为负，路径和不单调，不能因为中途已达到 limit 就直接保留整棵子树，也不能因为暂时不足就提前删除。

    解题步骤

    1. 空节点直接返回空。
    2. 原始叶子根据当前值与剩余额度比较，决定是否保留。
    3. 将 need-node.val 传给左右孩子，并接回剪枝结果。
    4. 原内部节点两侧都为空时删除，否则返回当前节点。

    示例：root=[1,2,3]、limit=4：根将额度 3 传给孩子。左叶子 2 不足，删除；右叶子 3 恰好达标，保留。结果为 [1,null,3]。 [5,-10]、limit=0 的唯一原始路径和为 -5，应删空；不能在删除孩子后把根重新当成达标叶子。

    代码实现

    class Solution {
    public TreeNode sufficientSubset(TreeNode root, int limit) {
        return dfs(root, limit);
    }

    // need 是从当前节点开始还需达到的路径和，尚未扣除当前值。
    private TreeNode dfs(TreeNode node, int need) {
        if (node == null) {
            return null;
        }

        if (node.left == null && node.right == null) {
            // 仅在原始叶子结算：路径不足才删除，等于阈值时保留。
            if (node.val < need) {
                return null;
            }

            return node;
        }

        // 子调用返回剪枝后的根，必须接回父节点。
        node.left = dfs(node.left, need - node.val);
        node.right = dfs(node.right, need - node.val);

        if (node.left == null && node.right == null) {
            return null;
        }

        return node;
    }
}

    func sufficientSubset(root *TreeNode, limit int) *TreeNode {
    return dfsSufficient(root, limit)
}

// need 是从当前节点开始还需达到的路径和，尚未扣除当前值。
func dfsSufficient(node *TreeNode, need int) *TreeNode {
    if node == nil {
        return nil
    }
    if node.Left == nil && node.Right == nil {
        // 仅在原始叶子结算：路径不足才删除，等于阈值时保留。
        if node.Val < need {
            return nil
        }
        return node
    }

    // 子调用返回剪枝后的根，必须接回父节点。
    node.Left = dfsSufficient(node.Left, need-node.Val)
    node.Right = dfsSufficient(node.Right, need-node.Val)

    if node.Left == nil && node.Right == nil {
        return nil
    }
    return node
}

    复杂度分析

    • 时间复杂度：$O(n)$，每个节点访问一次。
    • 空间复杂度：$O(h)$，h 为树高，来自递归栈；原地修改指针。

    关键点总结

    [!green]

    • 返回值表达修改后的子树，父节点必须接回它。
    • 先判断原始叶子，不能把剪枝后新变成的叶子重新作为完整路径结算。
    • 保留条件是存在达标路径，删除条件是所有路径都不足。

    易错点总结

    [!yellow]

    • 递归后不接回孩子：返回空不会自动断开父节点中的旧指针。
    • 把不足写成小于等于：路径恰好等于 limit 应保留。
    • 孩子删空后仍保留当前内部节点：新形成的短路径不属于原来的根到叶路径。
    • 中途达标就停止检查：后续负节点仍可能使整条路径不足。
