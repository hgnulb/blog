    题目描述

    ✅ 694. 不同岛屿的数量

    题意分析

    统计不同形状岛屿，形状仅允许平移后重合，不把旋转或镜像合并。当前实现把访问过的陆地改为零。

    解法：DFS 路径签名

    核心思路

    [!blue]

    按行优先扫描，让每个岛屿从同样的相对起点出发，再按固定方向顺序 DFS。记录进入方向与递归返回标记，得到与平移无关的遍历签名。

    只记录进入方向会丢失分支归属。返回标记是签名的一部分，不能当作路径回溯时删除的内容；它让相同方向分别属于哪个父节点可以被区分。

    解题步骤

    • 扫描未访问陆地，建立新的签名。
    • 进入格子时记录方向并置零，避免重复访问。
    • 按固定上、下、左、右顺序搜索。
    • 退出时追加返回标记，最后将完整签名加入集合。

    [[1,0],[1,1]] 与 [[1,1],[1,0]] 的进入序列都是 SDR，完整签名分别为 SDRBBB 与 SDBRBB，应算两种形状。

    代码实现

    class Solution {
    public int numDistinctIslands(int[][] grid) {
        Set<String> shapes = new HashSet<>();
        // 行优先选择一致起点，使平移形状得到同一锚点
        for (int row = 0; row < grid.length; row++) {
            for (int col = 0; col < grid[0].length; col++) {
                if (grid[row][col] == 1) {
                    StringBuilder path = new StringBuilder();
                    dfs(grid, row, col, 'S', path);
                    shapes.add(path.toString());
                }
            }
        }
        return shapes.size();
    }

    private void dfs(int[][] grid, int row, int col, char dir, StringBuilder path) {
        if (row < 0 || row >= grid.length || col < 0 || col >= grid[0].length || grid[row][col] == 0) {
            return;
        }
        grid[row][col] = 0;
        path.append(dir);
        // 所有岛屿按固定方向顺序遍历
        dfs(grid, row - 1, col, 'U', path);
        dfs(grid, row + 1, col, 'D', path);
        dfs(grid, row, col - 1, 'L', path);
        dfs(grid, row, col + 1, 'R', path);
        // 返回标记属于完整签名，不能回溯删除
        path.append('B');
    }
}

    func numDistinctIslands(grid [][]int) int {
    shapes := make(map[string]bool)
    var dfs func(int, int, byte, *[]byte)
    dfs = func(row int, col int, dir byte, path *[]byte) {
        if row < 0 || row >= len(grid) || col < 0 || col >= len(grid[0]) || grid[row][col] == 0 {
            return
        }
        grid[row][col] = 0
        *path = append(*path, dir)
        // 所有岛屿按固定方向顺序遍历
        dfs(row-1, col, 'U', path)
        dfs(row+1, col, 'D', path)
        dfs(row, col-1, 'L', path)
        dfs(row, col+1, 'R', path)
        // 返回标记属于完整签名，不能回溯删除
        *path = append(*path, 'B')
    }

    // 行优先选择一致起点，使平移形状得到同一锚点
    for row := 0; row < len(grid); row++ {
        for col := 0; col < len(grid[0]); col++ {
            if grid[row][col] == 1 {
                path := []byte{}
                dfs(row, col, 'S', &path)
                shapes[string(path)] = true
            }
        }
    }
    return len(shapes)
}

    复杂度分析

    • 时间复杂度：期望 $O(mn)$，每个格子最多访问一次，签名总长度线性。
    • 空间复杂度：$O(mn)$，保存签名集合及最坏递归栈。

    关键点总结

    [!green]

    • 起点规则和方向顺序必须一致。
    • 回退信息保留树状遍历结构。
    • 原地置零会修改输入网格。

    易错点总结

    [!yellow]

    • 只记录方向不记录返回，会混淆不同分支形状。
    • 每次任意挑起点，平移相同的岛屿可能得到不同签名。
    • 把旋转或镜像也归并，改变了本题等价条件。
